# SC-012 同答案双受众报告验收

**验收日期**：2026-07-26  
**环境**：staging `20.200.136.133`  
**内容版本**：`temp-v1`（临时测试文案）  
**验收器**：`scripts/test/staging-competency-dual-audience-report-e2e.py`

## 1. 验收方法

1. 创建两个标题、维度、时长、必填身份字段完全相同的胜任力测评。
2. 两个测评仅报告对象不同：`frontline_employee` 与 `leader`。
3. 两边均发布 D01、D02、D05、D06、D32，共 5 维度、40 题。
4. 使用相同人员字段，并按题号确定原始答案，确保 40 道题逐题输入一致，不受个人随机题序影响。
5. 分别提交、读取持久化结果、生成并下载真实 Chromium PDF。
6. 比较持久化整体结果、维度结果、维度顺序、精确文案来源、PDF 页面结构、规范化逐页文本和 72 DPI 栅格图。
7. 在 `finally` 中调用正式整链删除接口，清除测评、试卷、结果、报告实例、审计和 PDF 文件。
