# 胜任力测验候选题审阅稿（第 2 批）

**版本**：V0.2  
**日期**：2026-07-24  
**范围**：D05–D08，共 4 个维度、32 道题  
**状态**：AI 测试题初稿（已完成独立内容审查），未经过信效度验证  
**依据**：[胜任力测验需求说明书](competency-assessment-requirements.md)、[48 维度参考表](2600724胜任力测验维度.xlsx)

## 1. 本批生成规则

1. 每个维度直接生成 8 道候选题；
2. 全部使用中性职场措辞，不限定基层、管理者或特定行业；
3. 每个维度暂按 6 道正向题、2 道反向题配置；
4. 所有题目统一使用五级选项：非常不符合、不太符合、一般、比较符合、非常符合；
5. 正向题依次计 1、2、3、4、5 分，反向题依次计 5、4、3、2、1 分；
6. 考察点仅用于说明题目意图，不单独计分；
7. 一道题只归属于一个维度；
8. 题目避免包含具体组织、岗位、学历、年龄、性别等限制性信息。

> 重要说明：本批题目是供专家审阅的候选题，不代表已经完成心理测量学验证。正式用于人才评价前，应经过内容效度审核、认知访谈、预测试、项目分析和信效度检验；不宜仅凭 AI 初稿直接用于录用或淘汰决策。

## 2. 统一审核标记

请审核人将每题的“审核结论”填写为以下一种：

- **保留**：题意、归属和方向均可直接使用；
- **修改**：维度归属正确，但措辞需要调整；
- **删除**：与维度不符、与其他题重复或存在明显偏差；
- **待讨论**：存在跨维度边界或业务解释分歧。

建议审核时重点检查：

1. 是否只测量一个明确行为；
2. 是否准确归属于当前维度，而非相邻维度；
3. 是否容易被不同岗位的受测者理解；
4. 是否存在明显“正确答案”暗示或过强社会赞许性；
5. 反向题是否自然，是否避免双重否定；
6. 是否与本维度其他题内容重复；
7. 是否需要结合客户实际用语调整。

## 3. D05 逻辑思维

**核心含义**：推理有条理、有依据。  
**边界说明**：侧重区分事实与推测、检查前提和证据、保持推理一致；不直接测量发现问题根源、提出解决方案或从大量材料中提炼信息。

| 题目编号 | 题目 | 考察点 | 方向 | 审核结论 | 审核意见 |
|---|---|---|---|---|---|
| D05-Q01 | 分析一件事情时，我会区分已经确认的事实和个人推测。 | 事实区分 | 正向 | 待审核 |  |
| D05-Q02 | 得出结论前，我会检查现有依据是否足以支持该结论。 | 证据检验 | 正向 | 待审核 |  |
| D05-Q03 | 判断两个事项是否有关联时，我会考虑是否存在其他解释。 | 替代解释 | 正向 | 待审核 |  |
| D05-Q04 | 面对相互矛盾的说法时，我能指出它们在前提或结论上的不一致。 | 矛盾识别 | 正向 | 待审核 |  |
| D05-Q05 | 形成判断时，我会检查从已有依据到最终结论的每一步是否成立。 | 推理链检验 | 正向 | 待审核 |  |
| D05-Q06 | 当支持判断的关键依据改变时，我会重新检验该结论是否成立。 | 结论修正 | 正向 | 待审核 |  |
| D05-Q07 | 在依据尚不充分时，我会把初步印象当作确定结论。 | 过早判断 | 反向 | 待审核 |  |
| D05-Q08 | 分析事情时，我会先形成结论，再寻找能够支持它的依据。 | 结论先行 | 反向 | 待审核 |  |

### D05 审核提示

- `D05-Q03` 测量对替代解释的考虑，不要求受测者提出完整解决方案；
- `D05-Q05` 检查推理链本身，不评价沟通表达能力；
- `D05-Q06` 与适应性相邻，但本题仅考察关键依据变化后的结论复核；
- `D05-Q07`、`D05-Q08` 为反向题，预测试时需检查与正向题的镜像和社会赞许性。

## 4. D06 持续学习

**核心含义**：主动更新知识储备与技能。  
**边界说明**：侧重发现工作所需的学习缺口、获取知识、实践应用和持续更新；不以学历、培训机会、求知兴趣或追求新奇作为判断依据。

| 题目编号 | 题目 | 考察点 | 方向 | 审核结论 | 审核意见 |
|---|---|---|---|---|---|
| D06-Q01 | 发现现有知识不足以完成工作时，我会明确自己需要补充的内容。 | 学习缺口识别 | 正向 | 待审核 |  |
| D06-Q02 | 工作要求更新时，我会主动补充完成任务所需的新知识或技能。 | 主动更新 | 正向 | 待审核 |  |
| D06-Q03 | 学到新的工作方法后，我会在合适的任务中尝试使用。 | 学以致用 | 正向 | 待审核 |  |
| D06-Q04 | 应用新知识后，我会根据实际效果调整自己的理解。 | 学习反馈 | 正向 | 待审核 |  |
| D06-Q05 | 我会通过他人的反馈发现自己尚未掌握的知识或技能。 | 反馈学习 | 正向 | 待审核 |  |
| D06-Q06 | 我会把在工作中验证有效的新方法纳入后续的日常做法。 | 学习内化 | 正向 | 待审核 |  |
| D06-Q07 | 得知工作相关的方法已有更新时，我会等到原有做法无法满足任务要求后，才去了解更新内容。 | 更新及时性 | 反向 | 待审核 |  |
| D06-Q08 | 我会等到有人明确要求时，才补充工作所需的新知识或技能。 | 学习主动性 | 反向 | 待审核 |  |

### D06 审核提示

- `D06-Q02` 聚焦工作要求更新后的能力补充，不测量适应变化时的情绪或行为稳定性；
- `D06-Q03`、`D06-Q04` 分别测量尝试应用和根据结果校正理解；
- `D06-Q07`、`D06-Q08` 为反向题，需检查是否存在过强社会赞许性，以及与主动性、创新性、认知动机的跨维度载荷。

## 5. D07 组织协调

**核心含义**：推动跨部门协作与流程顺畅衔接。  
**边界说明**：侧重识别协作接口、同步依赖、协调顺序和推动交接闭环；不等同于愿意配合、善于交朋友或拥有正式管理权限。

| 题目编号 | 题目 | 考察点 | 方向 | 审核结论 | 审核意见 |
|---|---|---|---|---|---|
| D07-Q01 | 多方共同完成一项工作前，我会确认各方需要承担的事项。 | 职责确认 | 正向 | 待审核 |  |
| D07-Q02 | 自己的任务依赖他人先完成时，我会提前与相关人员确认衔接安排。 | 依赖协调 | 正向 | 待审核 |  |
| D07-Q03 | 多方任务在时间上相互依赖时，我会协调各方确认彼此的衔接节点。 | 节点协调 | 正向 | 待审核 |  |
| D07-Q04 | 协作要求发生变化时，我会把变化信息同步给直接受影响的相关方。 | 变更同步 | 正向 | 待审核 |  |
| D07-Q05 | 工作交接后，我会确认下一环节已经收到继续推进所需的信息。 | 交接闭环 | 正向 | 待审核 |  |
| D07-Q06 | 协作环节出现停滞时，我会推动相关方重新明确各自的衔接事项。 | 阻滞协调 | 正向 | 待审核 |  |
| D07-Q07 | 自己的进度会影响其他协作方时，我会等对方询问后再说明。 | 主动同步 | 反向 | 待审核 |  |
| D07-Q08 | 多方协作出现衔接问题时，即使我掌握了相关信息，我也会等别人先提出协调安排。 | 协调发起 | 反向 | 待审核 |  |

### D07 审核提示

- `D07-Q01` 关注协作职责接口，不测量管理者的正式分工权；
- `D07-Q03` 与统筹规划相邻，但本题仅针对既定协作任务中的衔接节点；
- `D07-Q06`、`D07-Q08` 与主动性相邻，预测试时需检查其是否主要反映“推动协调”而非一般主动行为；
- 本维度天然受跨部门协作机会和岗位权限影响，预测试需按岗位类别检查测量公平性。

## 6. D08 信息整合

**核心含义**：从碎片信息中提炼关键要点。  
**边界说明**：侧重汇集、分类、比较、关联和压缩零散信息；不直接测量推理是否正确、归纳一般规律或提出问题解决方案。

| 题目编号 | 题目 | 考察点 | 方向 | 审核结论 | 审核意见 |
|---|---|---|---|---|---|
| D08-Q01 | 收到多来源的信息后，我会按主题或用途进行归类。 | 信息分类 | 正向 | 待审核 |  |
| D08-Q02 | 整理当前任务的信息时，我会区分直接需要的内容和补充背景。 | 相关性筛选 | 正向 | 待审核 |  |
| D08-Q03 | 不同来源的信息不一致时，我会把差异对应到各自来源并单独标记。 | 差异标记 | 正向 | 待审核 |  |
| D08-Q04 | 我能把分散在不同材料中的相关信息对应起来。 | 关联整合 | 正向 | 待审核 |  |
| D08-Q05 | 整理多来源信息时，我会标出尚未获得但与当前任务直接相关的内容。 | 信息缺口识别 | 正向 | 待审核 |  |
| D08-Q06 | 汇总多来源信息时，我会围绕当前任务提炼关键要点。 | 要点提炼 | 正向 | 待审核 |  |
| D08-Q07 | 汇总多来源信息时，我会按收到的先后顺序排列，而不是按内容关系重组。 | 信息重组 | 反向 | 待审核 |  |
| D08-Q08 | 整合多来源信息时，我会忽略内容与其来源之间的对应关系。 | 来源对应 | 反向 | 待审核 |  |

### D08 审核提示

- `D08-Q03` 只要求对应来源并标记信息差异，不要求判断哪一方正确；
- `D08-Q05` 与问题解决相邻，但本题仅标出信息缺口，不要求诊断根因或提出方案；
- `D08-Q06` 与归纳总结相邻，但本题只提炼当前任务的关键要点，不推导一般规律。

## 8. 审核后处理

1. 汇总每道题的审核结论和修改意见；
2. 对“修改”和“待讨论”题目生成第二版措辞；
3. 检查 D05–D08 以及相邻维度之间的题目重复和串题风险；
4. 本批四个维度确认后，再生成下一批维度；
5. 48 个维度全部审定后，汇总为系统导入工作簿；
6. 正式上线前开展预测试，并依据项目分析结果决定是否替换题目。
