## 1. 交付文件

- Word模板：`competency-phase1-report-embedded.docx`
- 用途：调整报告版式、图片、文字、图表位置与图表样式。
- 格式：必须使用 Microsoft Word 保存为 `.docx`。

模板内置：

- 49个当前已使用的动态内容控件；
- 75个系统已注册业务字段（49个必需、26个可选）；
- 12个原生Word图表；
- 1个内嵌Excel工作簿；
- 10个固定二级维度及2个一级维度。

模板契约版本为`competency-phase1-template-schema-v2`。内嵌Excel的`FieldDictionary`工作表列出全部业务键、中文名称、类型、必需性、是否可重复、示例值和说明，客户不需要理解数据库字段或DOCX内部文件名。

## 2. 可以修改的内容

客户可以修改：

- 字体、字号、颜色、行距、段落间距；
- 页边距、分页符、表格行高与列宽；
- 封面图片、背景、装饰图形及其层级；
- 固定标题、阅读说明、维度定义、等级说明；
- 图表位置、大小、颜色、图例、线型、阴影和环形图孔径；
- 动态字段所在位置和显示样式。

## 3. 动态字段维护规则

动态值使用Word“纯文本内容控件”。页面显示的是示例内容，例如“张三”“3.50”“合格”，字段身份保存在内容控件属性的`Tag`中。

### 查看Tag

1. 在Word中启用“开发工具”选项卡；
2. 选中动态字段；
3. 点击“属性”；
4. 查看“标记（Tag）”。

### 禁止操作

- 不要删除内容控件后只保留普通文字；
- 不要修改或翻译Tag；
- 标记为“可重复”的Tag可以在封面、正文或页脚多次使用；标记为“不可重复”的Tag不得复制；
- 不要复制整个维度模块后保留原Tag；
- 不要将一个维度的得分、等级或诊断Tag放到另一个维度。

每个二级维度固定有3个Tag：

- `dimension.<维度ID>.score`
- `dimension.<维度ID>.level`
- `dimension.<维度ID>.diagnosis`

系统还提供可选字段，例如`overall.score`、`overall.percentage`、`participant.degree`、`participant.major`、`dimension.<维度ID>.remainingScore`和`dimension.<维度ID>.percentage`。在Word中新增纯文本内容控件并填写已注册Tag后即可使用，不需要修改数据库。完整清单以模板内`FieldDictionary`为准；未知Tag会在上传时被拒绝。

## 4. 图片和图形调整

建议使用“开始 → 选择 → 选择窗格”选择图片和图形。

- 可替换图片、改变大小、透明度及前后层级；
- 建议选择“固定在页面上的位置”；
- 明确设置文字环绕方式，避免对象随正文漂移；
- 调整后检查不同页面是否存在遮挡、裁切或跨页。

## 5. 图表和内嵌Excel

模板包含一个内嵌Excel工作簿。选中图表后，可使用“图表设计 → 编辑数据”打开它。

### 图表业务键

| 业务键 | 数据 |
|---|---|
| `chart.group.overview` | 通用能力、心理素养两个一级维度得分 |
| `chart.dimension.radar` | 十个二级维度雷达图 |
| `chart.dimension.<维度ID>` | 对应二级维度环形得分图 |

图表业务键保存在Word图表对象的“替代文字标题”中。程序根据“业务键 → Word关系ID → 实际图表文件”定位图表，不依赖`chart1.xml`～`chart12.xml`物理编号。Word重新编号内部图表文件不会改变业务含义。

### 内嵌Excel结构

- `FieldDictionary`：字段契约说明，只用于帮助客户理解和选择动态字段；
- `ChartData`：图表数据，A列为稳定业务键、B列为中文名称、C列为得分、D列为距满分差值；
- 运行时只更新`ChartData`数值列和图表缓存，不修改业务键及字段字典。

运行时系统会同时更新：

1. 内嵌Excel单元格；
2. Word图表XML缓存；
3. 图表旁的得分和等级内容控件。

### 图表调整规则

可以：

- 移动图表；
- 调整大小、配色、字体、图例和环形孔径；
- 调整图表与说明文字的相对位置。

不要：

- 删除图表后重新插入新图表；
- 复制图表替代其他维度图表，除非同时把“替代文字标题”改为目标业务图表键；
- 改变数据系列数量或数据点数量；
- 删除或重命名内嵌工作表`FieldDictionary`、`ChartData`；
- 修改图表的数据区域。

## 6. 分页要求

Microsoft Word与服务器LibreOffice的分页可能不同。客户完成调整后应：

1. 在Word中检查所有页面；
2. 确认无空白页、遮挡、裁切和孤立段落；
3. 将DOCX上传到测试环境；
4. 用真实测评结果生成PDF；
5. 以生成后的PDF作为最终分页验收依据。

## 7. 上传与回退

管理端入口：**测评管理 → 报告模板**。

上传时系统检查：

- DOCX结构；
- 49个必需内容控件Tag完整；
- 可选Tag必须来自75个已注册业务字段；
- 不可重复Tag唯一，可重复Tag允许多处使用；
- 12个图表业务键完整且唯一；
- `FieldDictionary`与`ChartData`结构；
- 1个内嵌工作簿、正确图表数据区域和零外部Excel链接；
- 不存在可见的`{{...}}`占位符。

校验失败不会覆盖当前模板。校验成功后系统先备份旧模板，再启用新模板。

## 9. 当前候选模板的重点修订项

当前内嵌Excel候选模板已在测试服务器用真实结果生成A4 PDF，共12个物理页。请客户优先检查：

1. **页脚总页数**：当前页脚显示“/13”，但实际PDF为12页，应统一为实际总页数或改用Word自动页数字段；
2. **第4页信息密度**：当前仅承载效度提示，页面留白较大，可与上一页总体评价合并；
3. **第5～6页跨页**：一级维度说明与二级雷达图发生跨页，建议调整段前距、表格高度或分页符；
4. **第7～12页维度卡片**：部分维度定义、环形图、得分、等级和诊断被拆到不同页面，建议每个维度模块设置为不可跨页或重新规划每页容纳数量；
5. **页面密度不均**：第11页内容较少，可与前后维度合并；
6. **图表旁文字对齐**：调整图表位置后，应检查“测评得分、评价等级”是否仍与对应图表同一视觉组；
7. **最终验收**：客户修改后重新上传测试环境，必须用真实结果再次生成PDF逐页确认。

以上属于版式修订，不需要修改内嵌Excel的数据区域、内容控件Tag或图表系列。
