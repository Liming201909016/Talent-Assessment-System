# 00401 一期胜任力报告模板客户维护说明（内嵌Excel版）

## 1. 交付文件

- Word模板：`competency-phase1-report-embedded.docx`
- 用途：调整报告版式、图片、文字、图表位置与图表样式。
- 格式：必须使用 Microsoft Word 保存为 `.docx`。

模板内置：

- 49个动态内容控件；
- 12个原生Word图表；
- 1个内嵌Excel工作簿；
- 10个固定二级维度及2个一级维度。

## 2. 可以修改的内容

客户可以修改：

- 字体、字号、颜色、行距、段落间距；
- 页边距、分页符、表格行高与列宽；
- 封面图片、背景、装饰图形及其层级；
- 固定标题、阅读说明、维度定义、等级说明；
- 图表位置、大小、颜色、图例、线型、阴影和环形图孔径；
- 动态字段所在位置和显示样式。

## 3. 动态字段维护规则

动态值使用Word“纯文本内容控件”。页面显示的是示例内容，例如“张三”“3.50”“合格”，字段身份保存在内容控件属性的`Tag`中。

### 查看Tag

1. 在Word中启用“开发工具”选项卡；
2. 选中动态字段；
3. 点击“属性”；
4. 查看“标记（Tag）”。

### 禁止操作

- 不要删除内容控件后只保留普通文字；
- 不要修改、翻译或重复使用Tag；
- 不要复制整个维度模块后保留原Tag；
- 不要将一个维度的得分、等级或诊断Tag放到另一个维度。

每个二级维度固定有3个Tag：

- `dimension.<维度ID>.score`
- `dimension.<维度ID>.level`
- `dimension.<维度ID>.diagnosis`

固定维度ID：

| A1-01 | competency-a1-01 | 逻辑思维 |
| A1-02 | competency-a1-02 | 数字应用 |

| A1-04 | competency-a1-04 | 持续学习 |

## 4. 图片和图形调整

建议使用“开始 → 选择 → 选择窗格”选择图片和图形。

- 可替换图片、改变大小、透明度及前后层级；
- 建议选择“固定在页面上的位置”；
- 明确设置文字环绕方式，避免对象随正文漂移；
- 调整后检查不同页面是否存在遮挡、裁切或跨页。

## 5. 图表和内嵌Excel

模板包含一个内嵌Excel工作簿。选中图表后，可使用“图表设计 → 编辑数据”打开它。

### 图表映射

| 图表 | 数据 |
|---|---|
| chart1 | 通用能力、心理素养两个一级维度得分 |
| chart2 | 十个二级维度雷达图 |
| chart3–chart12 | 十个二级维度环形得分图 |

运行时系统会同时更新：

1. 内嵌Excel单元格；
2. Word图表XML缓存；
3. 图表旁的得分和等级内容控件。

### 图表调整规则

可以：

- 移动图表；
- 调整大小、配色、字体、图例和环形孔径；
- 调整图表与说明文字的相对位置。

不要：

- 删除图表后重新插入新图表；
- 复制图表替代其他维度图表；
- 改变数据系列数量或数据点数量；
- 删除或重命名内嵌工作表`Sheet1`、`Sheet2`；
- 修改图表的数据区域。

## 6. 分页要求

Microsoft Word与服务器LibreOffice的分页可能不同。客户完成调整后应：

1. 在Word中检查所有页面；
2. 确认无空白页、遮挡、裁切和孤立段落；
3. 将DOCX上传到测试环境；
4. 用真实测评结果生成PDF；
5. 以生成后的PDF作为最终分页验收依据。

## 7. 上传与回退

管理端入口：**测评管理 → 报告模板**。

上传时系统检查：

- DOCX结构；
- 49个内容控件Tag完整且唯一；
- 12个图表结构；
- 不存在可见的`{{...}}`占位符。

校验失败不会覆盖当前模板。校验成功后系统先备份旧模板，再启用新模板。

## 8. 客户交付前检查清单

- [ ] 文件为DOCX；
- [ ] 49个内容控件未删除、未重复；
- [ ] 12个图表均存在；
- [ ] 内嵌Excel可通过“编辑数据”打开；
- [ ] 图表数据区域未修改；
- [ ] 图片和图形无重叠；
- [ ] 文字无裁切；
- [ ] 页眉、页脚和页码正确；
- [ ] Word中无异常空白页；
- [ ] 测试环境真实PDF已逐页确认。

## 9. 当前候选模板的重点修订项

当前内嵌Excel候选模板已在测试服务器用真实结果生成A4 PDF，共12个物理页。请客户优先检查：

1. **页脚总页数**：当前页脚显示“/13”，但实际PDF为12页，应统一为实际总页数或改用Word自动页数字段；
2. **第4页信息密度**：当前仅承载效度提示，页面留白较大，可与上一页总体评价合并；
3. **第5～6页跨页**：一级维度说明与二级雷达图发生跨页，建议调整段前距、表格高度或分页符；
4. **第7～12页维度卡片**：部分维度定义、环形图、得分、等级和诊断被拆到不同页面，建议每个维度模块设置为不可跨页或重新规划每页容纳数量；
5. **页面密度不均**：第11页内容较少，可与前后维度合并；
6. **图表旁文字对齐**：调整图表位置后，应检查“测评得分、评价等级”是否仍与对应图表同一视觉组；
7. **最终验收**：客户修改后重新上传测试环境，必须用真实结果再次生成PDF逐页确认。

以上属于版式修订，不需要修改内嵌Excel的数据区域、内容控件Tag或图表系列。
