# 胜任力测验候选题审阅稿（第 8 批）

**版本**：V0.1  
**日期**：2026-07-24  
**范围**：D29–D32，共 4 个维度、32 道题  
**状态**：仅测试用 AI 候选题初稿（待人工审核），未经过信效度验证  
**依据**：[胜任力测验需求说明书](competency-assessment-requirements.md)、[48 维度参考表](2600724胜任力测验维度.xlsx)

## 1. 本批生成规则

1. 每个维度直接生成 8 道候选题；
2. 全部使用中性职场措辞，不限定具体行业、组织、岗位、学历、年龄或性别；
3. 每个维度暂按 6 道正向题、2 道反向题配置；
4. 所有题目统一使用五级选项：非常不符合、不太符合、一般、比较符合、非常符合；
5. 正向题依次计 1、2、3、4、5 分，反向题依次计 5、4、3、2、1 分；
6. 每题聚焦一个明确的职场判断或行为，不把多个行为合并为一道题；
7. 考察点仅用于说明题目意图，不单独计分，且本批 32 道题的考察点不重复；
8. 一道题只归属于一个维度，并与相邻维度保持边界；
9. 题目避免模糊频率词、双重否定、绝对化表述和过于明显的正确答案暗示；
10. D30 不把沉默、隐瞒问题或盲从等同于组织忠诚；D31 不把自大、忽视证据或偏好风险等同于自信心。

> 重要说明：本批题目仅供测试和专家审阅，不代表已经完成心理测量学验证。正式用于人才评价前，应经过内容效度审核、认知访谈、预测试、项目分析和信效度检验；不得仅凭本批 AI 初稿直接用于录用、淘汰、晋升或其他人才决策。

## 2. 统一审核标记

请审核人将每题的“审核结论”填写为以下一种：

- **保留**：题意、归属和方向均可直接使用；
- **修改**：维度归属正确，但措辞需要调整；
- **删除**：与维度不符、与其他题重复或存在明显偏差；
- **待讨论**：存在跨维度边界或业务解释分歧。

建议审核时重点检查：

1. 是否只测量一个明确行为；
2. 是否准确归属于当前维度，而非相邻维度；
3. 是否容易被不同岗位的受测者理解；
4. 是否存在明显“正确答案”暗示或过强社会赞许性；
5. 反向题是否自然，是否避免双重否定；
6. 是否使用模糊频率词或绝对化措辞；
7. 是否与本批其他题内容或考察点重复；
8. 是否需要结合客户实际用语调整。

## 3. D29 担当作为

**核心含义**：面对困难主动挺身、不推诿退缩。  
**边界说明**：侧重在任务受阻、责任空档、结果不利或受到质疑时主动承接并持续承担职责；不等同于未经授权抢先行动、偏好高风险选择、单纯延长工作时间，也不以包揽超出能力或权限的事项作为担当。

| 题目编号 | 题目 | 考察点 | 方向 | 审核结论 | 审核意见 |
|---|---|---|---|---|---|
| D29-Q01 | 共同任务遇到阻碍且责任暂不清晰时，我会先接手其中可以推进的部分。 | 责任空档承接 | 正向 | 待审核 |  |
| D29-Q02 | 自己负责的工作出现偏差时，我会明确说明自己应承担的部分。 | 工作偏差认责 | 正向 | 待审核 |  |
| D29-Q03 | 接到职责范围内的棘手任务时，我会明确接下自己需要负责的部分。 | 棘手任务领责 | 正向 | 待审核 |  |
| D29-Q04 | 团队成员因突发困难无法继续负责时，我会在能力范围内补上关键环节。 | 突发缺位补位 | 正向 | 待审核 |  |
| D29-Q05 | 自己主导的方案受到质疑时，我会继续承担后续说明责任。 | 方案质疑担责 | 正向 | 待审核 |  |
| D29-Q06 | 自己负责的决定带来不利结果时，我会承担相应的补救工作。 | 不利结果补救 | 正向 | 待审核 |  |
| D29-Q07 | 任务可能引发争议时，我倾向于等责任人明确后再表态是否参与。 | 争议任务观望 | 反向 | 待审核 |  |
| D29-Q08 | 自己负责的工作出现棘手后果时，我会优先寻找他人接手处理。 | 棘手后果转移 | 反向 | 待审核 |  |

### D29 审核提示

- `D29-Q01`、`D29-Q04` 分别关注责任暂不清晰时的承接和明确缺位时的补位，需检查两题在认知访谈中能否被清楚区分；
- `D29-Q03` 限定在职责范围内，避免把越权、冒进或风险偏好误判为担当；
- `D29-Q05`、`D29-Q06` 关注对已主导事项的持续负责，不测量一般自信心或问题解决能力；
- 反向题不得把合理等待授权、专业分工或必要升级汇报误判为推诿，预测试时应重点检查情境解释。

## 4. D30 组织忠诚

**核心含义**：维护组织利益与声誉，始终如一。  
**边界说明**：侧重在不同处境下维护组织的合法长期利益、基于事实维护声誉并履行组织承诺；忠诚不等于对决定无条件赞同，也不等于沉默、隐瞒内部问题或对不当做法盲从。通过适当内部渠道提出异议，可以是维护组织长期利益的行为。

| 题目编号 | 题目 | 考察点 | 方向 | 审核结论 | 审核意见 |
|---|---|---|---|---|---|
| D30-Q01 | 对外谈及组织相关事项时，我会依据已核实的信息说明情况。 | 涉组事实表达 | 正向 | 待审核 |  |
| D30-Q02 | 发现内部做法可能损害组织声誉时，我会通过合适的内部渠道反映情况。 | 声誉隐患内报 | 正向 | 待审核 |  |
| D30-Q03 | 个人便利与组织长期利益发生冲突时，我会按组织长期利益调整自己的选择。 | 组织利益取舍 | 正向 | 待审核 |  |
| D30-Q04 | 面对针对组织的不实评价时，我会用可核实的事实作出澄清。 | 不实评价澄清 | 正向 | 待审核 |  |
| D30-Q05 | 组织处于困难阶段时，我会继续履行自己已经承担的职责。 | 困难阶段守责 | 正向 | 待审核 |  |
| D30-Q06 | 认为某项决定可能损害组织长期利益时，我会通过内部渠道提出异议。 | 长期利益异议 | 正向 | 待审核 |  |
| D30-Q07 | 组织的处境影响到个人利益时，我会减少对原有职责的投入。 | 利益受损撤回 | 反向 | 待审核 |  |
| D30-Q08 | 发现组织内部问题时，我会以保持一致为由不表达关切。 | 一致名义沉默 | 反向 | 待审核 |  |

### D30 审核提示

- `D30-Q01`、`D30-Q04` 均以事实为基础，避免把无依据辩护或掩盖问题当作维护组织声誉；
- `D30-Q02`、`D30-Q06` 测量通过内部渠道保护组织长期利益，不应因提出问题或异议而按不忠诚解释；
- `D30-Q05`、`D30-Q07` 关注组织处境变化时履责投入的一致性，需与敬业奉献区分；
- 预测试应检查题目是否诱发过强社会赞许性，并确认不同组织文化下“合适的内部渠道”具有可理解性。

## 5. D31 自信心

**核心含义**：确信自己的判断与能力。  
**边界说明**：侧重在具备依据、准备或相应能力时表达判断、承担适度挑战，并在质疑或失误后保持稳定的自我效能；不等同于高估自身、贬低他人、拒绝证据、忽视反馈、冲动决策或偏好风险。

| 题目编号 | 题目 | 考察点 | 方向 | 审核结论 | 审核意见 |
|---|---|---|---|---|---|
| D31-Q01 | 形成有依据的判断后，我会清楚表达自己的结论。 | 有据判断表达 | 正向 | 待审核 |  |
| D31-Q02 | 自己的判断与资深同事不同时，我会说明支撑判断的依据。 | 资历压力陈述 | 正向 | 待审核 |  |
| D31-Q03 | 接到能力范围内但有挑战的任务时，我愿意承担关键部分。 | 适度挑战承接 | 正向 | 待审核 |  |
| D31-Q04 | 会议需要当场判断时，我会基于掌握的信息提出自己的看法。 | 现场判断呈现 | 正向 | 待审核 |  |
| D31-Q05 | 他人质疑我的意见时，我会根据证据评估自己的判断。 | 质疑下证据复核 | 正向 | 待审核 |  |
| D31-Q06 | 一次判断出现偏差后，我仍会在充分准备的事项上提出自己的意见。 | 失误后再表达 | 正向 | 待审核 |  |
| D31-Q07 | 需要公开说明方案时，即使准备充分，我也会把说明机会让给别人。 | 充分准备仍回避 | 反向 | 待审核 |  |
| D31-Q08 | 多数人的看法与我不同时，我会收回尚未获得支持的意见。 | 多数压力收回 | 反向 | 待审核 |  |

### D31 审核提示

- `D31-Q01`、`D31-Q02` 测量有依据地表达判断，不把强势表达或否定他人当作自信；
- `D31-Q03` 明确限定在能力范围内，避免把冒险、过度承诺或成就动机误判为自信；
- `D31-Q05` 中根据证据调整判断不代表缺乏自信，审核时应检查受测者能否理解“开放复核”与“轻易动摇”的差异；
- `D31-Q07`、`D31-Q08` 可能受到职位层级、发言权限和团队文化影响，预测试需分组检查测量公平性。

## 6. D32 严谨性

**核心含义**：做事细致可靠、力求准确。  
**边界说明**：侧重对来源、要求、关联内容、交接状态和关键结论进行细致核验，使工作结果准确可靠；不等同于单纯把事项排列整齐、机械服从流程，也不鼓励脱离任务影响的过度检查或因追求完美而延误交付。

| 题目编号 | 题目 | 考察点 | 方向 | 审核结论 | 审核意见 |
|---|---|---|---|---|---|
| D32-Q01 | 提交包含数据的材料前，我会核对数据与原始来源是否一致。 | 源数一致核对 | 正向 | 待审核 |  |
| D32-Q02 | 处理包含多项要求的任务时，我会逐项确认关键要求的落实情况。 | 关键要求查验 | 正向 | 待审核 |  |
| D32-Q03 | 修改重要内容后，我会检查相关位置是否同步更新。 | 关联内容复核 | 正向 | 待审核 |  |
| D32-Q04 | 交接工作时，我会清楚标明尚未完成事项的当前状态。 | 未结状态标注 | 正向 | 待审核 |  |
| D32-Q05 | 发现结果中存在细小差异时，我会查明差异的来源。 | 细微差异追溯 | 正向 | 待审核 |  |
| D32-Q06 | 输出正式结果前，我会用另一种方式复核关键结论。 | 关键结论交叉验证 | 正向 | 待审核 |  |
| D32-Q07 | 材料整体看起来合理时，我会略过个别数据的再次核对。 | 整体合理省检 | 反向 | 待审核 |  |
| D32-Q08 | 时间接近截止点时，我会停止检查细节之间的一致性。 | 截止前停止细查 | 反向 | 待审核 |  |

### D32 审核提示

- `D32-Q01`、`D32-Q03`、`D32-Q06` 分别关注来源一致、关联一致和结论复核，需检查三者是否形成可区分的严谨行为；
- `D32-Q04` 关注交接信息的可靠性，不测量一般条理性或沟通表达风格；
- `D32-Q05` 关注对差异的准确追溯，不要求受测者独立解决差异背后的业务问题；
- `D32-Q08` 引入截止压力以降低正确答案暗示，预测试需确认其测量严谨性而非单纯测量时间资源充足程度。

## 8. 审核后处理

1. 汇总每道题的审核结论和修改意见；
2. 对“修改”和“待讨论”题目生成第二版措辞；
3. 检查 D29–D32 以及相邻维度之间的题目重复和串题风险；
4. 复核本批 32 个考察点的唯一性，并检查正反向题的自然度和社会赞许性；
5. 本批四个维度确认后，将审定结果纳入题库进度与后续汇总；
6. 48 个维度全部审定后，汇总为系统导入工作簿；
7. 正式上线前开展认知访谈和预测试，并依据项目分析及信效度检验结果决定保留、修改或替换题目。
