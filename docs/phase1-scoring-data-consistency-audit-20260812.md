# 00401 一期计分逻辑与数据一致性审计

**审计日期**：2026-08-12
**范围**：一期单题、二级维度、一级维度、总体分、效度分、CSV边界及报告标签
**结论**：核心后端计分与已确认的精确边界一致；原始说明存在1处确定错误、2处歧义，报告前端标签与CSV存在显示冲突。

## 1. 单题与二级维度

### 已实现逻辑

- 正向题：`final = raw`；
- 反向题：`final = 6 - raw`；
- 每个二级维度固定8题；
- `score_sum`保存8题转换后得分之和；
- `dimension_score = score_sum / 8`；
- 使用精确有理数计算，完成全部计算后才转DECIMAL(18,6)。

### 术语修正

“各维度原始得分”容易被理解为未反向转换的作答原值之和。实际应称为：

> 二级维度计分总和：该维度8题经正反向转换后的最终分之和。

### 五档边界

后端和CSV均采用下开上闭：

| 等级 | 精确区间 |
|---|---|
| L1 | `1.0 <= x <= 1.7` |
| L2 | `1.7 < x <= 2.7` |
| L3 | `2.7 < x <= 3.5` |
| L4 | `3.5 < x <= 4.3` |
| L5 | `4.3 < x <= 5.0` |

因为8题均为整数分，二级维度平均分只能以0.125递增，实际可达区间为：

| 等级 | 实际原始分和 | 实际可达平均分 |
|---|---:|---:|
| L1 | 8–13 | 1.000–1.625 |
| L2 | 14–21 | 1.750–2.625 |
| L3 | 22–28 | 2.750–3.500 |
| L4 | 29–34 | 3.625–4.250 |
| L5 | 35–40 | 4.375–5.000 |

1.7、2.7、4.3在单个二级维度上不可由8道整数题得到，但保留统一精确边界是合理的：一级维度平均由40道题间接形成，可达到0.025步长并命中这些边界。

## 2. 一级维度

- 通用能力：A1-01至A1-05五个二级维度平均分之和除以5；
- 心理素养：B1-01至B1-05五个二级维度平均分之和除以5；
- 任一子维度不完整时，该一级维度不生成正式分和等级；
- 完整一级维度复用L1–L5精确边界；
- CSV的一级标签为低分、较低分、中分、较高分、高分，与业务口径一致。

## 3. 总体分

### 正确公式

`T = D1 + D2 + ... + D10`，理论范围10–50，满分50。

### 确定矛盾

原始说明同时写：

- 50%–65%为薄弱胜任；
- 65%以下为尚未胜任。

两档在50%–65%区间重叠。这是确定错误。结合Excel五档和客户决策，应修正为：

| 内部码 | 总体等级 | 精确区间 | 满分比例 |
|---|---|---|---|
| excellent | 优秀胜任 | `45 <= T <= 50` | `>= 90%` |
| good | 良好胜任 | `40 <= T < 45` | `>= 80% 且 < 90%` |
| qualified | 合格胜任 | `32.5 <= T < 40` | `>= 65% 且 < 80%` |
| weak | 薄弱胜任 | `25 <= T < 32.5` | `>= 50% 且 < 65%` |
| not_qualified | 尚未胜任 | `10 <= T < 25` | `< 50%` |

后端和CSV当前已经使用上述修正值。

“90%以上”按Excel“45分以上”和已确认决策解释为包含90%，即45分属于优秀胜任。

## 4. 效度量表

### 歧义修正

“将所有题目得分相加”容易被误解为90道题全部相加。精确表述应为：

> 效度总分为10道效度题原始作答值之和，不进行反向转换，不进入二级、一级或总体分。

精确规则：

| 状态 | 条件 |
|---|---|
| good | 10题完整且 `10 <= V <= 35` |
| questionable | 10题完整且 `36 <= V <= 50` |
| incomplete | 少于10题完成，不生成正式效度分 |

当前后端按10道效度题的`raw_answer`求和，且强制效度题方向为forward；35属于good，36属于questionable，与确认口径一致。

## 5. 当前程序与CSV的一致项

- 80道维度题、10道效度题；
- 62道正向维度题、18道反向维度题；
- B1-04的8道维度题全部正向；
- 每个二级维度8题；
- 二级维度保存`score_sum`和平均分；
- 一级维度各聚合5个二级维度；
- 总体为10个二级平均分之和；
- 效度只聚合10道效度题原始值；
- 所有正式分均要求对应题目完整；
- 维度、一级、总体和效度边界均使用未提前四舍五入的精确值。

## 6. 当前显示层冲突

当前一期Vue将L1–L5显示为“起步级、发展级、胜任级、熟练级、卓越级”，但CSV规定：

- 二级维度：差、较差、合格、较优秀、优秀；
- 一级维度：低分、较低分、中分、较高分、高分。

同一个`phase1LevelLabel`无法同时正确显示一级和二级标签，应拆为两个映射。

当前总体内部码显示为“优秀、良好、合格、较弱、待提升”，CSV规定为“优秀胜任、良好胜任、合格胜任、薄弱胜任、尚未胜任”，也应修正。

这是报告显示问题，不影响数据库计分数值，但会造成报告文案与等级标签不一致。

## 7. 最终规范表述

1. 单题先按方向转换为最终分；维度计分总和为8题最终分之和。
2. 二级维度平均分为维度计分总和除以8，按下开上闭的L1–L5边界分级。
3. 一级维度得分为所属5个二级维度平均分的算术平均值，使用相同L1–L5边界，但显示一级标签。
4. 总体分为10个二级维度平均分之和，按`>=45 / >=40 / >=32.5 / >=25 / <25`分级；“尚未胜任”必须写为低于50%，不是低于65%。
5. 效度分仅为10道效度题原始作答值之和；`<=35`良好，`>35`存疑；效度不参与其他得分。
