# 胜任力测验候选题审阅稿（第 12 批）

**版本**：V0.2  
**日期**：2026-07-24  
**范围**：D45–D48，共 4 个维度、32 道题  
**状态**：AI 测试题初稿（已完成一次内容审查），未经过信效度验证  
**用途**：仅用于测试和专家审阅，不用于正式人才评价  
**依据**：[胜任力测验需求说明书](competency-assessment-requirements.md)、[48 维度参考表](2600724胜任力测验维度.xlsx)

## 1. 本批生成规则

1. 每个维度直接生成 8 道候选题；
2. 全部使用中性职场措辞，不限定具体行业、组织或岗位；
3. 每个维度暂按 6 道正向题、2 道反向题配置；
4. 所有题目统一使用五级选项：非常不符合、不太符合、一般、比较符合、非常符合；
5. 正向题依次计 1、2、3、4、5 分，反向题依次计 5、4、3、2、1 分；
6. 本批动机题测量偏好、吸引力和投入意愿，不把实际能力、工作表现或结果成败作为题目结论；
7. 每道题只包含一个主要陈述，且只归属于一个维度；
8. 题目避免模糊频率词、双重否定、绝对化措辞和明显“正确答案”；正反向题均采用可理解的偏好差异，不把任一选择写成失职、违规或道德缺陷；
9. 考察点仅用于说明题目意图，不单独计分；本批 32 道题的考察点均保持唯一；
10. 题目避免包含具体组织、岗位、学历、年龄、性别等限制性信息。

> 重要说明：本批题目仅供系统测试、内容检查和专家审阅，不代表已经完成心理测量学验证。正式用于人才评价前，应经过内容效度审核、认知访谈、预测试、项目分析和信效度检验；不得仅凭本批 AI 测试题用于录用、淘汰、晋升或其他人事决策。

## 2. 统一审核标记

请审核人将每题的“审核结论”填写为以下一种：

- **保留**：题意、归属和方向均可直接使用；
- **修改**：维度归属正确，但措辞需要调整；
- **删除**：与维度不符、与其他题重复或存在明显偏差；
- **待讨论**：存在跨维度边界或业务解释分歧。

建议审核时重点检查：

1. 是否只测量一个明确偏好或动机；
2. 是否准确归属于当前维度，而非相邻维度；
3. 是否容易被不同岗位的受测者理解；
4. 是否把“想要”误写成“能够做到”或实际表现；
5. 是否存在明显“正确答案”暗示或过强社会赞许性；
6. 反向题是否自然，是否避免双重否定；
7. 是否含有模糊频率词、绝对化措辞或两个并列判断；
8. 是否与本批其他题内容或考察点重复；
9. 是否需要结合客户实际用语调整。

## 3. D45 超越动机

**核心含义**：渴望不断突破自身极限。  
**边界说明**：侧重超越个人既有水平、最佳表现和自我设定的上限所带来的吸引力；不直接测量实际能力、抗压坚持或持续学习，也不等同于追求外部高难度成果的成就动机，或向他人证明能力的胜任动机。

| 题目编号 | 题目 | 考察点 | 方向 | 审核结论 | 审核意见 |
|---|---|---|---|---|---|
| D45-Q01 | 面对可以沿用熟悉做法的任务，我更愿意为自己设定高于以往表现的目标。 | 个人基准抬升 | 正向 | 待审核 |  |
| D45-Q02 | 完成既定要求后，继续提高个人表现上限的机会会吸引我。 | 达标后进阶 | 正向 | 待审核 |  |
| D45-Q03 | 与保持当前水平相比，突破自己已有的最佳表现更能激发我的投入。 | 最佳表现突破 | 正向 | 待审核 |  |
| D45-Q04 | 当工作留有提升空间时，我愿意尝试超出自己原有水平的要求。 | 原有水平跨越 | 正向 | 待审核 |  |
| D45-Q05 | 衡量个人进步时，我更看重自己是否超越了先前水平。 | 自我参照进步 | 正向 | 待审核 |  |
| D45-Q06 | 现有表现已符合要求时，我仍想探索自己还能达到怎样的更高水平。 | 潜在上限探索 | 正向 | 待审核 |  |
| D45-Q07 | 达到既定要求后，维持稳定表现比继续抬高个人标准更符合我的偏好。 | 稳定达标偏好 | 反向 | 待审核 |  |
| D45-Q08 | 选择任务时，我更看重能否稳定发挥现有水平，而非能否突破个人纪录。 | 现有水平维持 | 反向 | 待审核 |  |

### D45 审核提示

- `D45-Q01`、`D45-Q03` 以个人既有表现为参照，需与追求外部高难度目标的成就动机区分；
- `D45-Q05`、`D45-Q06` 关注自我突破的吸引力，不用于判断受测者实际能达到的水平；
- 本维度需与 D47 胜任动机区分：D45 关注超越自己，D47 关注证明自己的高水平能力。

## 4. D46 自主动机

**核心含义**：渴望按自己的节奏和方式行事。  
**边界说明**：侧重在目标、规则和协作要求明确的前提下，对工作方法、推进节奏和过程安排拥有选择空间的偏好；不测量独立完成工作的能力，也不把自主偏好解释为不合作、拒绝协调或抗拒规则。

| 题目编号 | 题目 | 考察点 | 方向 | 审核结论 | 审核意见 |
|---|---|---|---|---|---|
| D46-Q01 | 在目标和规则明确的前提下，我更愿意自己决定完成工作的具体方法。 | 方法选择自主 | 正向 | 待审核 |  |
| D46-Q02 | 当交付安排留有弹性时，按适合自己的节奏推进会让我更投入。 | 节奏掌控需求 | 正向 | 待审核 |  |
| D46-Q03 | 在需要协作的任务中，我希望保留对自己负责部分的安排空间。 | 协作内自主空间 | 正向 | 待审核 |  |
| D46-Q04 | 接受一项任务时，能够自主规划步骤会增强我承担这项工作的意愿。 | 步骤规划意愿 | 正向 | 待审核 |  |
| D46-Q05 | 面对多种合规做法时，我更偏好选择符合自己思路的一种。 | 合规路径选择 | 正向 | 待审核 |  |
| D46-Q06 | 与逐步接受具体指示相比，明确结果后自行组织过程更能调动我的积极性。 | 过程组织偏好 | 正向 | 待审核 |  |
| D46-Q07 | 即使可以自行安排，我也更喜欢由他人规定具体工作步骤。 | 外部步骤偏好 | 反向 | 待审核 |  |
| D46-Q08 | 在目标和规则不变的情况下，我更偏好沿用别人安排的推进节奏。 | 外部节奏偏好 | 反向 | 待审核 |  |

### D46 审核提示

- `D46-Q01`、`D46-Q05` 明确把自主空间限定在目标和规则之内，不用于判断规则意识；
- `D46-Q03` 测量协作情境中的安排空间，不把自主偏好写成回避配合；
- 高分不代表抗拒管理或协调，低分也不代表缺乏独立工作能力；预测试需检查不同岗位实际自主空间对作答的影响。

## 5. D47 胜任动机

**核心含义**：渴望证明自己具备高水平能力。  
**边界说明**：侧重获得展示、检验和证明个人专业水平机会的愿望；题目不判断受测者是否真的具备高水平能力，也不测量自信心、实际绩效或追求高难度目标本身。

| 题目编号 | 题目 | 考察点 | 方向 | 审核结论 | 审核意见 |
|---|---|---|---|---|---|
| D47-Q01 | 能够展示专业水准的任务比强调例行完成的任务更吸引我。 | 专业展示吸引 | 正向 | 待审核 |  |
| D47-Q02 | 在共同成果中能够清楚呈现个人贡献，会增强我的投入意愿。 | 个人贡献辨识 | 正向 | 待审核 |  |
| D47-Q03 | 我愿意让具备专业判断力的人根据工作成果评价我的水平。 | 专业评价意愿 | 正向 | 待审核 |  |
| D47-Q04 | 能够检验自己是否达到高水平标准的任务更能吸引我。 | 高标检验需求 | 正向 | 待审核 |  |
| D47-Q05 | 需要通过成果体现专业深度的任务更能激发我的投入。 | 专业深度举证 | 正向 | 待审核 |  |
| D47-Q06 | 当他人对我的专业水平存疑时，我更想用工作成果加以证明。 | 质疑回应驱动 | 正向 | 待审核 |  |
| D47-Q07 | 我更偏好个人表现保持低关注度的任务环境。 | 表现低关注偏好 | 反向 | 待审核 |  |
| D47-Q08 | 工作本身的体验比证明专业水平更能影响我的任务选择。 | 证明作用弱化 | 反向 | 待审核 |  |

### D47 审核提示

- 所有题目中的“水平”都是受测者希望展示或验证的对象，不能据此推断其实际能力；
- `D47-Q03`、`D47-Q04` 测量接受专业检验的动机，不等同于对自己判断和能力的确信；
- `D47-Q01`、`D47-Q05` 不以目标难度或结果达成为重点，需与成就动机区分；预测试还应检查表现可见性带来的印象管理偏差。

## 6. D48 社会动机

**核心含义**：渴望为群体或社会创造价值。  
**边界说明**：侧重群体受益、社会需要和更广泛影响对工作选择、意义感与投入意愿的吸引力；不评价个人道德是否正确，也不等同于无条件牺牲个人利益、日常助人行为或维护所在组织利益。

| 题目编号 | 题目 | 考察点 | 方向 | 审核结论 | 审核意见 |
|---|---|---|---|---|---|
| D48-Q01 | 在工作条件相近时，受益范围更广的任务对我更有吸引力。 | 受益范围偏好 | 正向 | 待审核 |  |
| D48-Q02 | 了解工作成果将如何改善某个群体的实际处境，会增强我的投入意愿。 | 群体处境联结 | 正向 | 待审核 |  |
| D48-Q03 | 选择工作方向时，回应社会实际需要的目标更能吸引我。 | 社会需要吸引 | 正向 | 待审核 |  |
| D48-Q04 | 当个人贡献能够汇入一项让群体共同受益的成果时，我更愿意投入。 | 共同受益参与 | 正向 | 待审核 |  |
| D48-Q05 | 工作成果对所在团队之外的人也有实际价值时，我会感到这项工作更有意义。 | 团队外价值感 | 正向 | 待审核 |  |
| D48-Q06 | 评估职业机会时，能否为群体创造可感知的价值会影响我的选择。 | 群体价值择业 | 正向 | 待审核 |  |
| D48-Q07 | 在工作条件相近时，能否回应群体需要对我的选择影响较小。 | 群体需要低权重 | 反向 | 待审核 |  |
| D48-Q08 | 与成果惠及范围相比，个人发展空间更能吸引我。 | 个人发展优先 | 反向 | 待审核 |  |

### D48 审核提示

- 本维度只测量群体或社会价值对个人选择的吸引力，不用于评价受测者是否善良、负责或具有更高道德水平；
- `D48-Q07`、`D48-Q08` 采用同样合理的职业偏好作为反向表述，避免把低社会动机写成失职或伤害他人；
- 需与利他精神、全局观念和组织忠诚区分，并在预测试中重点检查社会赞许性及“群体”“社会价值”等用语的理解一致性。

## 8. 审核后处理

1. 汇总每道题的审核结论和修改意见；
2. 对“修改”和“待讨论”题目生成第二版措辞；
3. 检查 D45–D48 以及相邻动机维度之间的题目重复和串题风险；
4. 对动机偏好、实际能力、社会赞许性和岗位机会差异开展专项内容复核；
5. 48 个维度全部审定后，汇总为系统导入工作簿；
6. 正式使用前开展认知访谈和预测试，并依据项目分析及信效度检验结果决定是否替换题目。
