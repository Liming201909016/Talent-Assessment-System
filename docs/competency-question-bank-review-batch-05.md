# 胜任力测验候选题审阅稿（第 5 批）

**版本**：V0.1  
**日期**：2026-07-24  
**范围**：D17–D20，共 4 个维度、32 道题  
**状态**：仅测试用的 AI 测试题初稿，未经过信效度验证  
**依据**：[胜任力测验需求说明书](competency-assessment-requirements.md)、[48 维度参考表](2600724胜任力测验维度.xlsx)

## 1. 本批生成规则

1. 每个维度生成 8 道候选题，题号在维度内连续；
2. 全部使用中性职场措辞，不限定具体行业、组织或岗位；D19 使用“成员”和“团队”，不要求受测者拥有正式下属；
3. 每个维度前 6 道为正向题，后 2 道为反向题；
4. 所有题目统一使用五级符合度选项：非常不符合、不太符合、一般、比较符合、非常符合；
5. 正向题依次计 1、2、3、4、5 分，反向题依次计 5、4、3、2、1 分；
6. 每道题只描述一个可观察行为，只归属于一个维度；
7. 题目避免模糊频率词、双重否定、绝对化表述和明显道德答案；
8. 考察点仅用于说明题目意图，不单独计分；本批考察点保持唯一且简短；
9. 题目避免包含具体组织、岗位、学历、年龄、性别等限制性信息。

> 重要说明：本批题目仅用于题库研发测试和专家审阅，不代表题目有效或已经完成心理测量学验证。正式用于人才评价前，应经过内容效度审核、认知访谈、预测试、项目分析和信效度检验；不得仅凭本 AI 初稿作出录用、淘汰或晋升决定。

## 2. 统一审核标记

请审核人将每题的“审核结论”填写为以下一种：

- **保留**：题意、归属和方向均可进入下一轮测试；
- **修改**：维度归属正确，但措辞需要调整；
- **删除**：与维度不符、与其他题重复或存在明显偏差；
- **待讨论**：存在跨维度边界或业务解释分歧。

建议审核时重点检查：

1. 是否只测量一个明确且可观察的行为；
2. 是否准确归属于当前维度，而非相邻维度；
3. 是否容易被不同岗位的受测者理解；
4. 是否存在明显“正确答案”暗示或过强社会赞许性；
5. 反向题是否自然，是否避免双重否定；
6. 是否与本批其他题内容或考察点重复；
7. 是否需要结合客户实际用语调整。

## 3. D17 资源整合

**核心含义**：识别并最大化利用内外部资源。  
**边界说明**：侧重盘点、寻找、连接和组合内外部资源，使其在任务中发挥更大作用；不直接测量资源优先次序与整体排期、目标追踪或以降低消耗为目的的成本优化。

|---|---|---|---|---|---|
| D17-Q01 | 承接一项新任务时，我会盘点可调用的内部和外部资源。 | 资源盘点 | 正向 | 待审核 |  |
| D17-Q02 | 任务出现资源缺口时，我会确认缺少的支持类型。 | 缺口定位 | 正向 | 待审核 |  |
| D17-Q03 | 其他团队已有适用成果时，我会推动在当前任务中复用该成果。 | 成果复用 | 正向 | 待审核 |  |
| D17-Q04 | 内部资源无法满足任务需要时，我会联系外部渠道寻求支持。 | 外部寻源 | 正向 | 待审核 |  |
| D17-Q05 | 不同资源各有局限时，我会设计相互补充的使用方式。 | 互补组合 | 正向 | 待审核 |  |
| D17-Q06 | 获得多方资源支持后，我会明确各项资源在任务中的衔接位置。 | 资源衔接 | 正向 | 待审核 |  |
| D17-Q07 | 需要额外支持时，我会将查找重点放在本团队已有资源上。 | 来源受限 | 反向 | 待审核 |  |

### D17 审核提示

- `D17-Q01`、`D17-Q02` 分别关注识别现有资源和定位资源缺口，需检查受测者能否清楚区分；
- `D17-Q03`、`D17-Q04` 关注跨团队复用和外部寻源，不以受测者拥有采购或正式协调权限为前提；
- `D17-Q05`、`D17-Q06` 测量资源组合与衔接，不测量 D14 统筹规划中的优先排序，也不以 D20 成本节约为判断标准。

**核心含义**：提前预判风险并做好应对准备。  
**边界说明**：侧重在风险发生前识别不确定因素、设置预警并准备应对安排；不直接测量问题发生后的根因分析、市场机会判断或组织长期方向选择。

| D18-Q02 | 评估一项风险时，我会判断它对工作结果的影响程度。 | 影响评估 | 正向 | 待审核 |  |

| D18-Q04 | 工作依赖外部条件时，我会检查可能中断的依赖环节。 | 依赖检查 | 正向 | 待审核 |  |
| D18-Q05 | 对已识别的风险，我会预先准备可启用的应对方案。 | 预案准备 | 正向 | 待审核 |  |

- `D18-Q08` 用较中性的方式描述单点依赖，预测试需确认其反向含义能否被稳定理解。

## 5. D19 绩效管理

**核心含义**：通过考核与反馈推动团队进步。  
**边界说明**：侧重依据标准评价成员或团队表现、提供具体反馈并跟踪改进；不直接测量目标分解、成员能力培养或团队凝聚。题目中的“成员”可指项目组、协作组或其他工作团队成员，不要求受测者与成员之间存在正式上下级关系。

| 题目编号 | 题目 | 考察点 | 方向 | 审核结论 | 审核意见 |
|---|---|---|---|---|---|
| D19-Q01 | 团队任务开始前，我会向成员说明用于评价工作结果的标准。 | 标准说明 | 正向 | 待审核 |  |
| D19-Q02 | 评估成员表现时，我会引用可核对的工作事实。 | 事实评价 | 正向 | 待审核 |  |
| D19-Q03 | 汇总团队表现时，我会识别多个成员共有的绩效差距。 | 团队差距 | 正向 | 待审核 |  |
| D19-Q04 | 成员表现与标准不一致时，我会指出具体差距。 | 差距反馈 | 正向 | 待审核 |  |
| D19-Q05 | 成员达到预期标准时，我会反馈其有效做法。 | 做法反馈 | 正向 | 待审核 |  |
| D19-Q06 | 与成员约定改进行动后，我会在约定节点核对后续表现。 | 改进跟踪 | 正向 | 待审核 |  |
| D19-Q07 | 成员完成任务后，我会用评价等级代替具体反馈。 | 等级替代 | 反向 | 待审核 |  |
| D19-Q08 | 阶段性差距出现时，我会等任务结束后再向团队反馈。 | 延迟反馈 | 反向 | 待审核 |  |

### D19 审核提示

- `D19-Q01` 关注绩效评价标准的透明度，不替代 D16 目标管理中的目标分解；
- `D19-Q03` 关注团队层面的共同绩效差距，不评价单个成员的能力潜力；
- `D19-Q05` 测量对有效做法的绩效反馈，需检查其是否被误解为一般性表扬；
- 本维度不依赖正式管理职权，预测试需按正式管理者、项目负责人和一般团队成员分组检查作答适用性。

## 6. D20 成本管控

**核心含义**：在保证质量前提下优化资源使用。  
**边界说明**：侧重在质量约束下估算、监控和优化资源消耗；不直接测量内外部资源的寻找与连接、整体资源优先排序，也不把降低质量作为控制成本的方式。

| 题目编号 | 题目 | 考察点 | 方向 | 审核结论 | 审核意见 |
|---|---|---|---|---|---|
| D20-Q01 | 安排任务投入前，我会估算完成工作所需的资源用量。 | 投入估算 | 正向 | 待审核 |  |
| D20-Q02 | 比较执行方案时，我会把约定的质量标准作为筛选条件。 | 质量约束 | 正向 | 待审核 |  |
| D20-Q03 | 执行过程中，我会核对实际资源消耗与预算之间的差异。 | 偏差监控 | 正向 | 待审核 |  |
| D20-Q04 | 多个环节重复使用同类资源时，我会调整为共享使用。 | 重复投入 | 正向 | 待审核 |  |
| D20-Q05 | 选择设备或服务时，我会比较整个使用周期产生的成本。 | 全周期成本 | 正向 | 待审核 |  |
| D20-Q06 | 质量达到约定标准时，我会选择资源消耗更低的方案。 | 低耗选择 | 正向 | 待审核 |  |
| D20-Q07 | 需要压缩成本时，我会按相同比例减少各项资源投入。 | 平均削减 | 反向 | 待审核 |  |
| D20-Q08 | 选择资源方案时，我会把初次投入金额作为首要依据。 | 初始价格 | 反向 | 待审核 |  |

### D20 审核提示

- `D20-Q01`、`D20-Q03` 分别关注事前估算和执行中的成本偏差监控；
- `D20-Q04` 以减少重复投入为目的，需与 D17 资源整合中的资源连接和组合区分；
- `D20-Q05`、`D20-Q08` 形成全周期成本与初始价格导向的对照，预测试需检查两题是否过度相关；
- `D20-Q07` 描述不区分质量影响的平均削减，审核时需确认反向含义清楚且不形成明显道德答案。

## 8. 审核后处理

1. 汇总每道题的审核结论和修改意见；
2. 对“修改”和“待讨论”题目生成第二版措辞；
3. 检查 D17–D20 以及相邻维度之间的题目重复和串题风险；
4. 检查本批 32 个考察点是否保持唯一、简短且与题目行为一致；
5. 完成人工内容审核后再进入认知访谈和预测试，不因本审阅稿形成而视为题目有效；
6. 依据项目分析和信效度检验结果决定保留、修改或替换题目；
7. 48 个维度全部审定后，再汇总为系统导入工作簿。
