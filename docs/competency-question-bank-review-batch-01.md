# 胜任力测验候选题审阅稿（第 1 批）

**版本**：V0.2  
**日期**：2026-07-24  
**范围**：D01–D04，共 4 个维度、32 道题  
**状态**：AI 测试题初稿（已完成独立内容审查），未经过信效度验证  
**依据**：[胜任力测验需求说明书](competency-assessment-requirements.md)、[48 维度参考表](2600724胜任力测验维度.xlsx)

## 1. 本批生成规则

1. 每个维度直接生成 8 道候选题；
2. 全部使用中性职场措辞，不限定基层、管理者或特定行业；
3. 每个维度暂按 6 道正向题、2 道反向题配置；
4. 所有题目统一使用五级选项：非常不符合、不太符合、一般、比较符合、非常符合；
5. 正向题依次计 1、2、3、4、5 分，反向题依次计 5、4、3、2、1 分；
6. 考察点仅用于说明题目意图，不单独计分；
7. 一道题只归属于一个维度；
8. 题目避免包含具体组织、岗位、学历、年龄、性别等限制性信息。

> 重要说明：本批题目是供专家审阅的候选题，不代表已经完成心理测量学验证。正式用于人才评价前，应经过内容效度审核、认知访谈、预测试、项目分析和信效度检验；不宜仅凭 AI 初稿直接用于录用或淘汰决策。

## 2. 统一审核标记

请审核人将每题的“审核结论”填写为以下一种：

- **保留**：题意、归属和方向均可直接使用；
- **修改**：维度归属正确，但措辞需要调整；
- **删除**：与维度不符、与其他题重复或存在明显偏差；
- **待讨论**：存在跨维度边界或业务解释分歧。

建议审核时重点检查：

1. 是否只测量一个明确行为；
2. 是否准确归属于当前维度，而非相邻维度；
3. 是否容易被不同岗位的受测者理解；
4. 是否存在明显“正确答案”暗示或过强社会赞许性；
5. 反向题是否自然，是否避免双重否定；
6. 是否与本维度其他题内容重复；
7. 是否需要结合客户实际用语调整。

## 3. D01 沟通表达

**核心含义**：清晰传递与接收信息。  
**边界说明**：侧重信息表达、理解确认和沟通方式选择；不以外向程度、人际亲和力或关系动机作为判断依据。

|---|---|---|---|---|---|
| D01-Q01 | 说明工作内容时，我会围绕重点安排表达顺序。 | 结构化表达 | 正向 | 待审核 |  |
| D01-Q02 | 面对知识背景不同的沟通对象，我会调整用词和说明方式。 | 对象适配 | 正向 | 待审核 |  |
| D01-Q03 | 听取重要事项时，我会针对尚未理解的关键信息提出具体问题。 | 主动澄清 | 正向 | 待审核 |  |
| D01-Q04 | 收到重要信息后，我会用自己的话复述，以确认理解无误。 | 理解确认 | 正向 | 待审核 |  |
| D01-Q05 | 当讨论双方理解不一致时，我会说明分歧所在。 | 分歧说明 | 正向 | 待审核 |  |
| D01-Q06 | 我能根据事项的紧急程度和复杂程度选择合适的沟通方式。 | 方式选择 | 正向 | 待审核 |  |
| D01-Q07 | 说明事情时，我难以取舍与重点无关的细节。 | 表达简明度 | 反向 | 待审核 |  |
| D01-Q08 | 对方未反馈时，我会默认其已经理解所传递的信息。 | 反馈确认 | 反向 | 待审核 |  |

### D01 审核提示

- `D01-Q03`、`D01-Q04` 分别测量主动提问和复述确认，预测试时需检查两者是否可区分；
- `D01-Q06` 测量沟通媒介和方式选择，不是计划能力；
- `D01-Q07`、`D01-Q08` 为反向题，需确认措辞是否符合客户语言习惯。

## 4. D02 人际交往

**核心含义**：建立和维护积极的工作关系。  
**边界说明**：侧重建立关系、维持互动和修复分歧的能力；不等同于喜欢社交、服从他人或无条件迁就。

| 题目编号 | 题目 | 考察点 | 方向 | 审核结论 | 审核意见 |
|---|---|---|---|---|---|
| D02-Q01 | 我能与工作风格不同的人保持稳定、友好的工作关系。 | 差异相处 | 正向 | 待审核 |  |
| D02-Q02 | 与新的协作对象共事时，我能建立必要的工作联系。 | 关系建立 | 正向 | 待审核 |  |
| D02-Q03 | 与他人出现分歧后，我仍能就工作事项与对方正常互动。 | 分歧修复 | 正向 | 待审核 |  |
| D02-Q04 | 对方明确表达互动边界后，我会据此调整后续往来。 | 边界调整 | 正向 | 待审核 |  |
| D02-Q05 | 与他人意见不同时，我会先了解对方最关注的事项。 | 关注理解 | 正向 | 待审核 |  |
| D02-Q06 | 我能通过持续、可靠的互动逐步赢得他人的信任。 | 信任建立 | 正向 | 待审核 |  |
| D02-Q07 | 与他人建立工作联系后，我较难持续维护后续互动。 | 关系维护 | 反向 | 待审核 |  |
| D02-Q08 | 对某人形成负面印象后，这种印象会妨碍我维持正常的工作往来。 | 关系客观性 | 反向 | 待审核 |  |

### D02 审核提示

- `D02-Q01` 关注关系稳定性，不评价对方工作能力；
- `D02-Q05` 与“合作性”相邻，但本题重点是理解对方关注点，而非是否愿意配合；
- `D02-Q07` 聚焦已有关系的持续维护，避免把内向程度当成人际交往能力。

## 5. D03 数字应用

**核心含义**：熟练运用数据工具处理工作。  
**边界说明**：侧重使用电子表格或其他数据工具完成整理、处理、核验和呈现；不直接测量数学天赋、逻辑思维或数据分析岗位经验。

| 题目编号 | 题目 | 考察点 | 方向 | 审核结论 | 审核意见 |
|---|---|---|---|---|---|
| D03-Q01 | 我能根据工作任务选择合适的数据处理工具。 | 工具选择 | 正向 | 待审核 |  |
| D03-Q02 | 使用数据工具时，我能将不同来源的数据转换为统一格式。 | 数据整理 | 正向 | 待审核 |  |
| D03-Q03 | 使用数据工具处理一批记录时，我能按条件筛选所需数据。 | 数据筛选 | 正向 | 待审核 |  |
| D03-Q04 | 处理数据后，我会检查异常值或关键结果，避免明显错误。 | 数据核验 | 正向 | 待审核 |  |
| D03-Q05 | 需要呈现数据时，我能用工具将结果整理成便于读取的表格。 | 数据呈现 | 正向 | 待审核 |  |
| D03-Q06 | 遇到重复的数据处理任务时，我会复用已设置好的处理模板。 | 模板复用 | 正向 | 待审核 |  |
| D03-Q07 | 工具已提供批量功能时，我仍倾向于逐项手工处理。 | 批量处理意识 | 反向 | 待审核 |  |
| D03-Q08 | 数据格式变化后，我难以相应调整工具的处理设置。 | 工具适应性 | 反向 | 待审核 |  |

### D03 审核提示

- 本维度容易受岗位的数据使用频率影响，后续预测试应记录岗位类别并检查测量公平性；
- `D03-Q02` 与“信息整合”相邻，但本题强调数据格式和工具操作；
- `D03-Q06` 对数字工具熟练度要求较高，需确认是否适用于全部目标人群。

## 6. D04 计划执行

**核心含义**：高效推进计划并达成预期结果。  
**边界说明**：侧重个人任务的计划、进度跟踪和调整执行；不测量管理者的战略目标分解、团队绩效管理或资源统筹权力。

| 题目编号 | 题目 | 考察点 | 方向 | 审核结论 | 审核意见 |
|---|---|---|---|---|---|
| D04-Q01 | 接到一项任务后，我会把目标拆分为明确的行动步骤。 | 任务分解 | 正向 | 待审核 |  |
| D04-Q02 | 多项由我负责的任务同时出现时，我会综合重要性与时限确定处理顺序。 | 优先排序 | 正向 | 待审核 |  |
| D04-Q03 | 开始执行前，我会为主要行动步骤设定完成节点。 | 节点设定 | 正向 | 待审核 |  |
| D04-Q04 | 执行任务时，我会在预定节点核对实际进度。 | 进度跟踪 | 正向 | 待审核 |  |
| D04-Q05 | 发现进度落后时，我会重新安排后续步骤。 | 纠偏执行 | 正向 | 待审核 |  |
| D04-Q06 | 任务完成前，我会对照预定要求确认产出结果。 | 结果闭环 | 正向 | 待审核 |  |
| D04-Q07 | 任务已有明确计划时，我仍倾向于推迟其中的行动步骤。 | 及时推进 | 反向 | 待审核 |  |
| D04-Q08 | 计划被打断后，我难以重新确定后续步骤的顺序。 | 中断恢复 | 反向 | 待审核 |  |

### D04 审核提示

- `D04-Q01` 测量个人行动计划，不是“目标管理”维度；
- `D04-Q02` 仅限本人负责的任务排序，不测量跨团队资源统筹；
- `D04-Q06` 补充“达成预期结果”的结果闭环；
- `D04-Q07`、`D04-Q08` 与自律性、适应性相邻，预测试时需检查跨维度载荷。

## 8. 审核后处理

1. 汇总每道题的审核结论和修改意见；
2. 对“修改”和“待讨论”题目生成第二版措辞；
3. 检查相邻维度之间的题目重复和串题风险；
4. 本批四个维度确认后，再生成下一批维度；
5. 48 个维度全部审定后，汇总为系统导入工作簿；
6. 正式上线前开展预测试，并依据项目分析结果决定是否替换题目。
