# 00401 一期客户样例报告模板实现

**日期**：2026-08-12
**状态**：本地实现并验证，未部署
**数据契约**：`competency-phase1-csv-v1`

客户DOCX是报告完整样例契约，包含固定格式、固定文本、变量位置、条件变化文本和示例分数，不仅是视觉参考。字段分类与维护边界见`docs/phase1-report-template-contract-20260812.md`。

## 1. 数据来源

报告中的业务名称和描述不在Vue中重复维护：

- 一级维度名称与说明：phase1-report-static-texts.csv；
- 二级维度ID、编号、名称、核心含义、定义：phase1-dimensions.csv；
- 二级/一级等级名称和区间：phase1-dimension-levels.csv；
- 总体等级内部码、名称和区间：phase1-overall-levels.csv；
- 当前结果对应的总体、维度诊断与效度提示：后端按CSV未来导入的正式报告文案精确匹配；
- 测评名称、人员信息、完成时间和用时：后端结果及测评快照。

`scripts/tools/generate-competency-phase1-report-catalog.js`先调用CSV校验器，再确定性生成前端运行目录`src/data/competencyPhase1ReportCatalog.js`。生成文件禁止手工修改。

## 2. 十页结构

1. 绿色封面：报告名称、测评名称、受测者、报告日期；
2. 报告阅读说明：两组十维矩阵、一级说明和最终免责声明；
3. 个人信息、总体得分/等级/诊断、效度提示；
4. 两个一级维度得分、等级和说明；
5. 十个二级维度10轴雷达图、得分和等级；
6. 逻辑思维、数字应用；
7. 计划执行、持续学习；
8. 沟通表达、敬业奉献；
9. 求真务实、自律性；
10. 成就导向、合作意识。

二级详情页每个维度显示CSV定义、得分、二级等级标签和当前等级诊断与建议。

## 3. 标签口径

- 二级维度：差、较差、合格、较优秀、优秀；
- 一级维度：低分、较低分、中分、较高分、高分；
- 总体：优秀胜任、良好胜任、合格胜任、薄弱胜任、尚未胜任。

旧的起步级/发展级/胜任级/熟练级/卓越级以及较弱/待提升不再用于一期正式模板。

## 4. 隐私和内容门禁

- 受测者报告不显示效度原始分、35/36阈值或`validityScore`；
- 当前CSV已加入明确标记的效度良好AI建议稿，但仍为`pending_review`；客户DOCX特别说明已作为draft免责声明候选，package仍为draft且双批准为空；
- 后端双批准与文案完整性门禁保持不变，缺失内容时不返回报告DTO、不生成PDF；
- 模板不提供兜底正式文案，不将建议稿冒充客户已批准内容。

## 6. 再生成命令

人工修改CSV并通过校验后，应重新执行报告目录生成器，再执行`--check`确认工作区目录未过期。正式导入和部署仍需另行执行备份、事务替换和完整报告验收。
