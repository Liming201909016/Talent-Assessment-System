# 胜任力测验候选题审阅稿（第 9 批）

**版本**：V0.2  
**日期**：2026-07-24  
**范围**：D33–D36，共 4 个维度、32 道题  
**状态**：仅测试用的 AI 候选题初稿（已完成一次内容审查），未经过信效度验证  
**依据**：[胜任力测验需求说明书](competency-assessment-requirements.md)、[48 维度参考表](2600724胜任力测验维度.xlsx)

## 1. 本批生成规则

1. 每个维度直接生成 8 道候选题，题目编号在维度内连续；
2. 全部使用中性职场措辞，不限定具体行业、组织或岗位；
3. 每个维度按前 6 道正向题、后 2 道反向题配置；
4. 所有题目统一使用五级符合度选项：非常不符合、不太符合、一般、比较符合、非常符合；
5. 正向题依次计 1、2、3、4、5 分，反向题依次计 5、4、3、2、1 分；
6. 每道题只描述一个可观察行为，只归属于一个维度；
7. 每道题的考察点在本批 32 道题内唯一，仅用于说明题目意图，不单独计分；
8. 题干不使用“总是、从不、经常、通常、往往、容易、倾向于”等模糊频率或倾向词；
9. 题干避免双重否定、绝对化措辞和明显道德答案，也不包含性别、年龄、学历等限制性信息；
10. D35 通过协商、理由评估、边界替代和共同推进测量合作，不把无条件接受他人意见视为高合作；
11. D36 以达到决策条件后的及时选择测量果断，不把缺少依据的快速行动视为果断。

> **重要说明：本批题目仅测试用。** 题目只可用于专家内容审核、认知访谈和预测试，尚未经过项目分析、信度检验或效度检验。正式用于人才评价前，必须完成心理测量学验证；不得仅凭本稿用于录用、淘汰、晋升等人才决策。

## 2. 统一审核标记

请审核人将每题的“审核结论”填写为以下一种：

- **保留**：题意、归属和方向均可直接使用；
- **修改**：维度归属正确，但措辞需要调整；
- **删除**：与维度不符、与其他题重复或存在明显偏差；
- **待讨论**：存在跨维度边界或业务解释分歧。

建议审核时重点检查：

1. 是否只测量一个明确且可观察的行为；
2. 是否准确归属于当前维度，而非相邻维度；
3. 是否容易被不同岗位的受测者理解；
4. 是否存在明显“正确答案”暗示或过强社会赞许性；
5. 反向题是否自然，是否避免双重否定；
6. 考察点是否在本批内唯一，题目内容是否彼此重复；
7. D35 是否把合作误写成顺从，D36 是否把果断误写成冲动；
8. 是否需要结合客户实际用语调整。

## 3. D33 自律性

**核心含义**：自我约束、不松懈、不逾矩。  
**边界说明**：侧重在缺少外部监督、个人便利或情绪干扰下维持自我约束，并守住资源和权限边界；不直接测量对制度内容的认知、工作结果的准确性、压力承受水平或单纯的工作投入程度。

| 题目编号 | 题目 | 考察点 | 方向 | 审核结论 | 审核意见 |
|---|---|---|---|---|---|
| D33-Q01 | 没有他人现场监督时，我会按已确认的要求推进自己负责的工作。 | 无监督履约 | 正向 | 待审核 |  |
| D33-Q02 | 工作中出现与当前任务无关的干扰时，我会把注意力拉回手头事项。 | 干扰回焦 | 正向 | 待审核 |  |
| D33-Q03 | 可以自主使用工作资源时，我会先确认用途是否在约定范围内。 | 资源边界核对 | 正向 | 待审核 |  |
| D33-Q04 | 面对需要持续投入的任务，我会按约定节奏保持投入。 | 长程自持 | 正向 | 待审核 |  |
| D33-Q05 | 情绪受到影响时，我会调整表达方式后再参与工作讨论。 | 表达克制 | 正向 | 待审核 |  |
| D33-Q06 | 个人安排与已承诺的工作节点冲突时，我会优先兑现工作承诺。 | 承诺优先 | 正向 | 待审核 |  |
| D33-Q07 | 阶段成果距离检查还有一段时间时，我会把投入强度降下来。 | 检查前松懈 | 反向 | 待审核 |  |
| D33-Q08 | 当事项超出当前权限且等待确认会延误进度时，我会按自己的判断先行推进。 | 权限越界 | 反向 | 待审核 |  |

### D33 审核提示

- `D33-Q01`、`D33-Q04` 关注缺少即时监督或反馈时的自我维持，需与敬业奉献、计划执行区分；
- `D33-Q03`、`D33-Q08` 关注个人拥有操作空间时是否自我守界，不考察受测者能否复述制度内容；
- `D33-Q05` 只测量受影响后的表达约束，需在预测试中检查其与抗压性、情绪稳定相关题目的区分度。

## 4. D34 条理性

**核心含义**：工作安排井然有序、有章法。  
**边界说明**：侧重把任务、资料、进度和交接信息组织成清晰结构；不直接测量计划是否达成、细节是否准确、管理层面的资源配置或跨部门协调效果。

| 题目编号 | 题目 | 考察点 | 方向 | 审核结论 | 审核意见 |
|---|---|---|---|---|---|
| D34-Q01 | 接到包含多个环节的任务时，我会先理清各环节的处理顺序。 | 环节排序 | 正向 | 待审核 |  |
| D34-Q02 | 处理多类工作资料时，我会按用途分类放置。 | 资料分类 | 正向 | 待审核 |  |
| D34-Q03 | 同时推进多项事项时，我会用统一清单记录各项所处阶段。 | 进度可视 | 正向 | 待审核 |  |
| D34-Q04 | 交接工作时，我会按事项整理需要传递的信息。 | 交接归整 | 正向 | 待审核 |  |
| D34-Q05 | 临时事项加入后，我会重新排定手头工作的先后次序。 | 插单重排 | 正向 | 待审核 |  |
| D34-Q06 | 完成阶段工作后，我会把相关文件归入对应位置。 | 阶段归档 | 正向 | 待审核 |  |
| D34-Q07 | 事情集中出现时，我会按想到的先后切换处理事项。 | 随性切换 | 反向 | 待审核 |  |
| D34-Q08 | 为了随手记录，我会把同一事项的信息保存在多个位置。 | 记录分散 | 反向 | 待审核 |  |

### D34 审核提示

- `D34-Q01`、`D34-Q05` 只关注安排结构，不以任务最终是否完成判断计划执行能力；
- `D34-Q02`、`D34-Q06` 测量资料组织方式，不以文件内容是否准确判断严谨性；
- `D34-Q03`、`D34-Q04` 可能受团队工具和流程影响，预测试需检查不同工作环境下的可答性。

## 5. D35 合作性

**核心含义**：乐于配合、不固执己见。  
**边界说明**：侧重在共同目标下理解分歧、协商调整、补位支持并保留合理边界；不把无条件接受他人意见、服从权威或放弃独立判断视为合作，也不直接测量人际亲和、利他付出或跨部门流程协调。

| 题目编号 | 题目 | 考察点 | 方向 | 审核结论 | 审核意见 |
|---|---|---|---|---|---|
| D35-Q01 | 共同任务中他人的安排发生变化时，我会协商调整自己的衔接方式。 | 变更协商 | 正向 | 待审核 |  |
| D35-Q02 | 同事提出不同意见时，我会询问其判断依据。 | 异议求证 | 正向 | 待审核 |  |
| D35-Q03 | 共同任务出现临时缺口时，我会与相关同事协商自己可以承担的部分。 | 缺口补位 | 正向 | 待审核 |  |
| D35-Q04 | 他人的配合请求超出我的可承受范围时，我会提出可行的替代配合方式。 | 边界替代 | 正向 | 待审核 |  |
| D35-Q05 | 方案讨论出现分歧时，我会在不影响关键目标的部分调整自己的主张。 | 非关键让步 | 正向 | 待审核 |  |
| D35-Q06 | 同事指出我的做法影响协作时，我会根据具体影响调整做法。 | 反馈调整 | 正向 | 待审核 |  |
| D35-Q07 | 共同任务需要改变接口方式时，我会坚持沿用自己的原有做法。 | 接口固守 | 反向 | 待审核 |  |
| D35-Q08 | 自己的方案未被采用时，我会把后续推进留给方案提出者。 | 异议后撤 | 反向 | 待审核 |  |

### D35 审核提示

- `D35-Q02` 要求了解不同意见的依据，而不是直接接受对方观点；
- `D35-Q04` 将合理边界与替代方案同时纳入情境，用于避免把无条件配合测成高合作；
- `D35-Q05`、`D35-Q07` 关注分歧中的可调整程度，需与缺乏主见区分；`D35-Q08` 关注方案落选后的共同推进，不评价方案本身优劣。

## 6. D36 果断性

**核心含义**：关键时刻不犹豫、快速拍板。  
**边界说明**：侧重在决策条件达到或时限受限时及时收束并承担选择；不把未经判断的抢先行动视为果断，也不直接测量冒险偏好、自信表达、主动发起或长期战略判断。

| 题目编号 | 题目 | 考察点 | 方向 | 审核结论 | 审核意见 |
|---|---|---|---|---|---|
| D36-Q01 | 完成决策所需的关键信息已经明确时，我会及时作出选择。 | 信息到位决断 | 正向 | 待审核 |  |
| D36-Q02 | 多个方案各有利弊且时间有限时，我会依据关键标准确定方案。 | 标准取舍 | 正向 | 待审核 |  |
| D36-Q03 | 需要在职责范围内拍板时，我会明确给出决定。 | 职责拍板 | 正向 | 待审核 |  |
| D36-Q04 | 紧急情况下只能获得部分信息时，我会依据已掌握的关键事实作出阶段性决定。 | 有限信息决断 | 正向 | 待审核 |  |
| D36-Q05 | 作出决定后，面对不影响结论的新意见，我会按既定方向推进。 | 决定稳定 | 正向 | 待审核 |  |
| D36-Q06 | 决策窗口即将结束时，我会在窗口结束前明确采用的方案。 | 限时定案 | 正向 | 待审核 |  |
| D36-Q07 | 各方案都存在不足时，我会继续等待更理想的选择再作决定。 | 完美等待 | 反向 | 待审核 |  |
| D36-Q08 | 需要我明确选择时，我会等更多人先表态后再作决定。 | 表态依赖 | 反向 | 待审核 |  |

### D36 审核提示

- `D36-Q02`、`D36-Q04` 均保留判断依据，用于区分果断与缺少评估的快速行动；
- `D36-Q05` 将情境限定为新意见不影响结论，避免把固执测成果断；
- `D36-Q08` 描述决策职责已经明确后仍依赖他人先表态，不否定决策前的合理征询。

## 8. 审核后处理

1. 汇总每道题的审核结论和修改意见；
2. 对“修改”和“待讨论”题目生成第二版措辞，并再次检查单一行为和计分方向；
3. 检查 D33–D36 内部以及与规则意识、计划执行、严谨性、组织协调、抗压性等相邻维度的重复和串题风险；
4. 对 D35 单独检查“合作—顺从”区分，对 D36 单独检查“果断—冲动”区分；
5. 开展认知访谈和预测试，检查题意理解、岗位公平性、社会赞许性及反向题方法效应；
6. 依据项目难度、区分度、题总相关、内部一致性和结构效度结果决定保留、修改或替换题目；
7. 只有通过内容审核和信效度验证的题目，才可汇总进入正式系统导入工作簿。
