# 胜任力测验候选题审阅稿（第 4 批）

**版本**：V0.2

**状态**：AI 测试题初稿，仅测试用，未经过信效度验证  
**依据**：[胜任力测验需求说明书](competency-assessment-requirements.md)、[48 维度参考表](2600724胜任力测验维度.xlsx)

## 1. 本批生成规则

1. 每个维度生成 8 道候选题；
2. 全部使用中性职场措辞，不限定具体行业；D15 统一使用“成员”“同事”等中性称谓；
3. 每个维度按 6 道正向题、2 道反向题配置；
4. 所有题目统一使用五级选项：非常不符合、不太符合、一般、比较符合、非常符合；
5. 正向题依次计 1、2、3、4、5 分，反向题依次计 5、4、3、2、1 分；
6. 每题设置一个唯一且简短的考察点，考察点仅说明题目意图，不单独计分；
7. 每题只陈述一个可观察行为，且只归属于一个维度；
8. 题干不使用模糊频率词，不采用双重否定、绝对化表达或明显社会赞许性措辞，也不包含具体组织、岗位、学历、年龄、性别等限制性信息。

> 重要说明：本批题目仅用于测试与专家审阅，是未经信效度验证的 AI 初稿，不代表题目有效，也不应直接用于录用、晋升、淘汰或其他人才决策。正式使用前须完成内容效度审核、认知访谈、预测试、项目分析和信效度检验。

## 2. 统一审核标记

请审核人将每题的“审核结论”填写为以下一种：

- **保留**：题意、归属和方向均可直接使用；
- **修改**：维度归属正确，但措辞需要调整；
- **删除**：与维度不符、与其他题重复或存在明显偏差；
- **待讨论**：存在跨维度边界或业务解释分歧。

建议审核时重点检查：

1. 是否只测量一个明确且可观察的行为；
2. 是否准确归属于当前维度，而非相邻维度；
3. 是否容易被不同岗位的受测者理解；
4. 是否存在明显“正确答案”暗示或过强社会赞许性；
5. 反向题是否自然，是否避免双重否定；
6. 是否与本维度其他题内容重复；
7. 是否需要结合客户实际用语调整。

## 3. D13 商业洞察

**核心含义**：捕捉市场变化并预判机会与风险。  
**边界说明**：侧重识别外部市场信号并判断其商业含义，包括需求、竞争、规则、机会与风险；不直接测量组织长期方向、一般信息整理、具体风险应对方案或客户服务行为。

|---|---|---|---|---|---|
| D13-Q01 | 评估业务机会时，我会查找客户需求变化的具体信息。 | 需求变化捕捉 | 正向 | 待审核 |  |
| D13-Q02 | 发现竞争者调整产品或服务时，我会分析这项调整可能改变的市场格局。 | 竞争动态判断 | 正向 | 待审核 |  |
| D13-Q03 | 看到行业规则变化时，我会判断它对现有业务的影响。 | 规则影响判断 | 正向 | 待审核 |  |
| D13-Q04 | 市场信号出现变化时，我会区分短期波动与持续趋势。 | 趋势辨别 | 正向 | 待审核 |  |
| D13-Q05 | 评估市场变化时，我会明确其中可以转化为业务机会的条件。 | 机会条件识别 | 正向 | 待审核 |  |
| D13-Q06 | 提出业务方案前，我会核对相关市场变化可能带来的商业风险。 | 商业风险预判 | 正向 | 待审核 |  |
| D13-Q07 | 评估新机会时，我会把当前业务表现作为判断的主要依据。 | 内部表现锚定 | 反向 | 待审核 |  |
| D13-Q08 | 市场出现初步变化时，我会等到它影响现有结果后再评估其业务含义。 | 信号评估滞后 | 反向 | 待审核 |  |

### D13 审核提示

- `D13-Q04` 关注市场信号的趋势含义，不评价组织长期发展方向；
- `D13-Q05`、`D13-Q06` 分别关注机会条件和商业风险，不要求受测者制定资源方案或风险预案；
- `D13-Q07` 以当前业务表现作为主要依据，需检查其反向含义是否足够清晰且不过度直白。

## 4. D14 统筹规划

**核心含义**：合理配置资源、确定优先次序。  
**边界说明**：侧重在多任务约束下确定优先次序、配置现有资源、安排任务依赖与调整空间；不直接测量单项计划执行、跨部门协作、新资源获取、成本节约或目标分解追踪。

| 题目编号 | 题目 | 考察点 | 方向 | 审核结论 | 审核意见 |
|---|---|---|---|---|---|
| D14-Q01 | 安排多项工作时，我会依据目标重要性确定处理顺序。 | 优先级排序 | 正向 | 待审核 |  |
| D14-Q02 | 资源不足以同时支持多项任务时，我会优先保障关键任务的资源需求。 | 关键资源保障 | 正向 | 待审核 |  |
| D14-Q03 | 制定整体安排前，我会逐项核对不同任务所需的人员、时间和工具。 | 资源需求核对 | 正向 | 待审核 |  |
| D14-Q04 | 安排相互关联的任务时，我会根据前后依赖确定启动顺序。 | 依赖关系排程 | 正向 | 待审核 |  |
| D14-Q05 | 制定计划时，我会为关键节点预留调整空间。 | 关键节点余量 | 正向 | 待审核 |  |
| D14-Q06 | 工作条件发生变化时，我会重新排序任务优先级。 | 动态优先级 | 正向 | 待审核 |  |
| D14-Q07 | 多项任务同时提出资源需求时，我会按提出先后分配资源。 | 先到先配 | 反向 | 待审核 |  |

### D14 审核提示

- `D14-Q01` 关注多项工作的优先次序，不测量目标本身的分解；
- `D14-Q03` 将人员、时间和工具作为资源示例，需检查不同岗位是否均能据此作答；
- `D14-Q05` 关注计划中的调整余量，不替代风险识别与应对准备；
- `D14-Q07`、`D14-Q08` 需检查反向表述是否受岗位资源配置权限影响。

## 5. D15 人才培养

**核心含义**：帮助他人成长、能够独当一面。  
**边界说明**：侧重识别成员的发展重点，通过挑战性任务、方法指导、行为反馈和逐步放手促进独立胜任；不直接测量团队凝聚、绩效评价、受测者自身学习或临时协助同事完成任务。

| 题目编号 | 题目 | 考察点 | 方向 | 审核结论 | 审核意见 |
|---|---|---|---|---|---|
| D15-Q01 | 与成员讨论成长方向时，我会结合其当前能力明确下一项发展重点。 | 发展重点识别 | 正向 | 待审核 |  |
| D15-Q02 | 安排发展任务时，我会让成员承担略高于其现有熟练程度的工作。 | 适度挑战 | 正向 | 待审核 |  |
| D15-Q03 | 成员首次承担新任务时，我会说明完成任务所需的关键方法。 | 关键方法指导 | 正向 | 待审核 |  |
| D15-Q04 | 成员完成发展任务后，我会针对其具体行为提供反馈。 | 具体行为反馈 | 正向 | 待审核 |  |
| D15-Q05 | 成员掌握关键方法后，我会逐步减少对其操作过程的介入。 | 渐进放手 | 正向 | 待审核 |  |
| D15-Q06 | 检验培养效果时，我会让成员独立完成同类任务。 | 独立胜任检验 | 正向 | 待审核 |  |
| D15-Q07 | 成员处理新任务遇到困难时，我会接手其中的关键部分。 | 代替完成 | 反向 | 待审核 |  |
| D15-Q08 | 为降低出错风险，我会把发展任务限定在成员熟悉的工作范围内。 | 挑战回避 | 反向 | 待审核 |  |

### D15 审核提示

- `D15-Q01` 关注发展重点识别，不把当前表现直接转化为绩效评价；
- `D15-Q02`、`D15-Q08` 从正反两面考察发展任务的挑战度，需检查任务安排权限带来的岗位差异；
- `D15-Q03` 关注方法指导，与直接接手成员任务相区分；
- `D15-Q05`、`D15-Q06` 关注成员独立胜任，不等同于一般工作授权。

## 6. D16 目标管理

**核心含义**：科学分解目标并持续追踪达成。  
**边界说明**：侧重把整体目标转化为可验收的阶段目标，明确衡量方式与责任归属，并依据检查节点持续比较进展、纠正偏差；不直接测量共同目标动员、资源优先配置、日常执行推进或绩效评价。

| 题目编号 | 题目 | 考察点 | 方向 | 审核结论 | 审核意见 |
|---|---|---|---|---|---|
| D16-Q01 | 接到整体目标后，我会把它分解为可单独验收的阶段目标。 | 阶段目标分解 | 正向 | 待审核 |  |
| D16-Q02 | 设定阶段目标时，我会明确判断完成程度的衡量指标。 | 衡量指标明确 | 正向 | 待审核 |  |
| D16-Q03 | 分配具体目标时，我会明确对应的责任人。 | 目标责任归属 | 正向 | 待审核 |  |
| D16-Q04 | 确定目标推进方式时，我会设置阶段检查节点。 | 阶段检查设置 | 正向 | 待审核 |  |
| D16-Q05 | 跟踪目标时，我会把实际进展与阶段目标进行对照。 | 目标进展对照 | 正向 | 待审核 |  |
| D16-Q06 | 发现目标进度偏离时，我会明确需要调整的后续行动。 | 进度偏差纠正 | 正向 | 待审核 |  |
| D16-Q07 | 整体目标明确后，我会把最终结果作为推进过程中的主要检查依据。 | 最终结果依赖 | 反向 | 待审核 |  |
| D16-Q08 | 目标推进过程中，我会等到临近截止时间再集中核对完成情况。 | 目标检查滞后 | 反向 | 待审核 |  |

### D16 审核提示

- `D16-Q01`、`D16-Q02` 分别关注目标分解和衡量标准，需检查两题是否保持清晰区分；
- `D16-Q03` 关注目标责任归属，不涉及对责任人的绩效评定；
- `D16-Q04`、`D16-Q05` 关注持续检查机制，不测量资源排期；
- `D16-Q07`、`D16-Q08` 需检查受测者能否稳定识别依赖最终结果和延迟检查的反向含义。
