# 胜任力测验候选题审阅稿（第 3 批）

**版本**：V0.2  
**日期**：2026-07-24  
**范围**：D09–D12，共 4 个维度、32 道题  
**状态**：AI 测试题初稿（已完成一次内容审查），未经过信效度验证  
**依据**：[胜任力测验需求说明书](competency-assessment-requirements.md)、[48 维度参考表](2600724胜任力测验维度.xlsx)

## 1. 本批生成规则

1. 每个维度直接生成 8 道候选题；
2. 全部使用中性职场措辞，不限定具体行业；D11、D12 不使用“下属”等正式管理身份词；
3. 每个维度暂按 6 道正向题、2 道反向题配置；
4. 所有题目统一使用五级选项：非常不符合、不太符合、一般、比较符合、非常符合；
5. 正向题依次计 1、2、3、4、5 分，反向题依次计 5、4、3、2、1 分；
6. 考察点仅用于说明题目意图，不单独计分；
7. 一道题只归属于一个维度；
8. 题目避免包含具体组织、岗位、学历、年龄、性别等限制性信息。

> 重要说明：本批题目是供专家审阅的候选题，不代表已经完成心理测量学验证。正式用于人才评价前，应经过内容效度审核、认知访谈、预测试、项目分析和信效度检验；不宜仅凭 AI 初稿直接用于录用或淘汰决策。

## 2. 统一审核标记

请审核人将每题的“审核结论”填写为以下一种：

- **保留**：题意、归属和方向均可直接使用；
- **修改**：维度归属正确，但措辞需要调整；
- **删除**：与维度不符、与其他题重复或存在明显偏差；
- **待讨论**：存在跨维度边界或业务解释分歧。

建议审核时重点检查：

1. 是否只测量一个明确行为；
2. 是否准确归属于当前维度，而非相邻维度；
3. 是否容易被不同岗位的受测者理解；
4. 是否存在明显“正确答案”暗示或过强社会赞许性；
5. 反向题是否自然，是否避免双重否定；
6. 是否与本维度其他题内容重复；
7. 是否需要结合客户实际用语调整。

## 3. D09 问题解决

**核心含义**：找到问题根源并拿出有效方案。  
**边界说明**：侧重界定问题、验证原因、形成可行方案并检查解决效果；不直接测量一般推理能力、信息整理能力或对未来风险的提前预判。

| 题目编号 | 题目 | 考察点 | 方向 | 审核结论 | 审核意见 |
|---|---|---|---|---|---|
| D09-Q01 | 处理问题前，我会先明确实际情况与预期结果之间的差距。 | 问题界定 | 正向 | 待审核 |  |
| D09-Q02 | 问题反复出现时，我会追查尚未消除的根本原因。 | 根因追查 | 正向 | 待审核 |  |
| D09-Q03 | 判断问题原因时，我会寻找能够验证不同原因假设的信息。 | 原因验证 | 正向 | 待审核 |  |
| D09-Q04 | 形成解决思路时，我会比较不止一种可行办法。 | 方案比较 | 正向 | 待审核 |  |
| D09-Q05 | 选择解决方案时，我会确认它在现有条件下能够执行。 | 方案可行性 | 正向 | 待审核 |  |
| D09-Q06 | 实施解决方案后，我会核对原有问题是否得到解决。 | 效果验证 | 正向 | 待审核 |  |
| D09-Q07 | 处理非紧急问题时，我会在核实主要原因前就确定解决办法。 | 过早定案 | 反向 | 待审核 |  |
| D09-Q08 | 同一问题反复出现时，我仍把重点放在缓解眼前影响上。 | 表层缓解 | 反向 | 待审核 |  |

### D09 审核提示

- `D09-Q03` 使用逻辑推理验证原因，但目标是定位具体问题根因，不是一般逻辑能力；
- `D09-Q04` 测量方案形成阶段，不要求受测者拥有正式决策权；
- `D09-Q06` 关注问题是否消除，不等同于绩效结果考核。

## 4. D10 归纳总结

**核心含义**：从具体信息中提炼规律与结论。  
**边界说明**：侧重跨多个具体案例识别共性、条件、例外并形成可复用结论；不只是压缩当前材料的关键要点，也不评价结论的表达风格。

| 题目编号 | 题目 | 考察点 | 方向 | 审核结论 | 审核意见 |
|---|---|---|---|---|---|
| D10-Q01 | 回顾多个相似案例时，我会找出其中反复出现的共同特征。 | 共性识别 | 正向 | 待审核 |  |
| D10-Q02 | 比较不同结果时，我会关注哪些条件随结果一起发生变化。 | 条件比较 | 正向 | 待审核 |  |
| D10-Q03 | 总结经验时，我会区分普遍现象和个别例外。 | 例外区分 | 正向 | 待审核 |  |
| D10-Q04 | 分析多个具体事例后，我能形成可以概括这些事例的结论。 | 概括结论 | 正向 | 待审核 |  |
| D10-Q05 | 根据多个事例形成结论前，我会留意这些事例是否覆盖了不同情况。 | 情况覆盖 | 正向 | 待审核 |  |
| D10-Q06 | 后来遇到新的事例时，我会核对它是否符合此前总结的规律。 | 规律复核 | 正向 | 待审核 |  |
| D10-Q07 | 总结一组案例时，我会停留在逐项描述，而不提炼共同结论。 | 结论提炼 | 反向 | 待审核 |  |
| D10-Q08 | 少数事例出现相似结果时，我会认为这种结果适用于大多数情况。 | 草率概括 | 反向 | 待审核 |  |

### D10 审核提示

- `D10-Q01`、`D10-Q04` 分别关注识别共性和形成概括结论；
- `D10-Q05` 与逻辑思维相邻，但本题只检查归纳样本的代表性；
- `D10-Q06` 通过新案例检验规律，需在预测试中检查是否过度依赖受测者的案例分析机会。

## 5. D11 战略思维

**核心含义**：从全局和长远视角把握方向。  
**边界说明**：侧重把当前行动放入组织整体和长期发展中判断方向；不直接测量市场信息敏感度、具体资源排期或单项风险处置。题目采用一般“重要工作/组织方向”场景，不要求受测者拥有正式战略决策职权。

| 题目编号 | 题目 | 考察点 | 方向 | 审核结论 | 审核意见 |
|---|---|---|---|---|---|
| D11-Q01 | 评估一项重要工作时，我会考虑它与组织整体目标的关系。 | 整体目标关联 | 正向 | 待审核 |  |
| D11-Q02 | 判断当前选择时，我会考虑它在较长时期内可能产生的影响。 | 长期影响 | 正向 | 待审核 |  |
| D11-Q03 | 一项做法能改善局部结果时，我也会考虑它对其他工作环节的影响。 | 全局影响 | 正向 | 待审核 |  |
| D11-Q04 | 评估未来方向时，我会考虑外部环境变化可能带来的影响。 | 环境前瞻 | 正向 | 待审核 |  |
| D11-Q05 | 比较不同发展方向时，我会关注它们各自对组织长期发展的作用。 | 方向比较 | 正向 | 待审核 |  |
| D11-Q06 | 阶段性结果与长期方向不一致时，我会重新审视当前做法。 | 长短期校准 | 正向 | 待审核 |  |
| D11-Q07 | 判断一项选择的价值时，我更看重眼前结果，而较少考虑长期影响。 | 短期导向 | 反向 | 待审核 |  |
| D11-Q08 | 判断一项工作是否值得投入时，我更看重本环节的结果，而较少考虑它对组织整体方向的作用。 | 局部导向 | 反向 | 待审核 |  |

### D11 审核提示

- `D11-Q03` 关注局部与整体关系，不测量跨部门任务衔接；
- `D11-Q04` 与商业洞察、风险防范相邻，但本题只用于判断长期方向；
- 本维度受战略信息接触和决策参与机会影响，预测试需按岗位层级检查测量公平性。

## 6. D12 团队领导

**核心含义**：凝聚团队力量实现共同目标。  
**边界说明**：侧重建立共同目标、促进参与、维持投入并以行动带动团队；不依赖正式管理职位，不测量跨部门流程协调、下属培养或绩效考核。

| 题目编号 | 题目 | 考察点 | 方向 | 审核结论 | 审核意见 |
|---|---|---|---|---|---|
| D12-Q01 | 共同任务开始时，我会帮助团队成员理解这项任务的共同目标。 | 目标共识 | 正向 | 待审核 |  |
| D12-Q02 | 推动团队工作时，我会说明个人贡献与共同目标之间的联系。 | 贡献联结 | 正向 | 待审核 |  |
| D12-Q03 | 讨论团队任务时，我会邀请尚未表达意见的成员参与。 | 参与促进 | 正向 | 待审核 |  |
| D12-Q04 | 团队成员意见不一致时，我会引导讨论回到共同目标。 | 分歧引导 | 正向 | 待审核 |  |
| D12-Q05 | 团队遇到挫折时，我会带动成员把注意力转向仍可推进的行动。 | 挫折带动 | 正向 | 待审核 |  |
| D12-Q06 | 团队需要持续投入时，我会用自己的行动带动成员共同推进。 | 行动示范 | 正向 | 待审核 |  |
| D12-Q07 | 推进共同任务时，我更关注成员各自完成分工，而较少关注团队是否形成合力。 | 合力忽视 | 反向 | 待审核 |  |
| D12-Q08 | 团队投入状态下降时，我会等到已经影响任务推进后才介入。 | 延迟带动 | 反向 | 待审核 |  |

### D12 审核提示

- `D12-Q01`、`D12-Q02` 关注共同目标和贡献意义，不替代目标分解或绩效管理；
- `D12-Q03`、`D12-Q04` 与沟通表达、合作性相邻，但本题目的在于凝聚团队参与；
- 本维度需要受测者具有团队影响机会，预测试需按正式管理者、项目负责人和一般成员分组检查公平性。

## 8. 审核后处理

1. 汇总每道题的审核结论和修改意见；
2. 对“修改”和“待讨论”题目生成第二版措辞；

6. 正式上线前开展预测试，并依据项目分析结果决定是否替换题目。
