# 胜任力测验候选题审阅稿（第 11 批）

**版本**：V0.2  
**日期**：2026-07-24  
**范围**：D41–D44，共 4 个维度、32 道题  
**状态**：AI 测试题初稿（已完成一次内容审查），未经过信效度验证  
**依据**：[胜任力测验需求说明书](competency-assessment-requirements.md)、[48 维度参考表](2600724胜任力测验维度.xlsx)

## 1. 本批生成规则

1. 每个维度直接生成 8 道候选题；
2. 全部使用中性职场措辞，不限定具体行业、组织或正式管理身份；
3. 每个维度暂按 6 道正向题、2 道反向题配置，题目编号在维度内连续；
4. 所有题目统一使用五级选项：非常不符合、不太符合、一般、比较符合、非常符合；
5. 正向题依次计 1、2、3、4、5 分，反向题依次计 5、4、3、2、1 分；
6. 考察点仅用于说明题目意图，不单独计分，且本批 32 道题的考察点互不重复；
7. 一道题只归属于一个维度，每道题只表达一个主要判断；
8. 动机题测量内在愿望、兴趣、偏好或满足感，不以能力高低、行为熟练度或行为频率替代动机；
9. 题目避免模糊频率词、双重否定、绝对化表述和明显的道德正确答案；
10. D42 正式名称统一使用“权力动机”；高分表示希望拥有建设性的影响力和主导权，不表示倾向支配、控制或强迫他人；
11. D43 不以沟通、维护关系或处理冲突的能力替代关系动机；D44 不以参加培训、更新知识等持续学习行为替代认知动机。

> 重要说明：本批题目仅供测试和专家审阅，不代表已经完成心理测量学验证。正式用于人才评价前，应经过内容效度审核、认知访谈、预测试、项目分析和信效度检验；不得仅凭本批 AI 测试题直接用于录用、淘汰或其他重大人才决策。

## 2. 统一审核标记

请审核人将每题的“审核结论”填写为以下一种：

- **保留**：题意、归属和方向均可直接使用；
- **修改**：维度归属正确，但措辞需要调整；
- **删除**：与维度不符、与其他题重复或存在明显偏差；
- **待讨论**：存在跨维度边界或业务解释分歧。

建议审核时重点检查：

1. 是否只表达一个主要判断；
2. 是否测量内在偏好或愿望，而不是能力、技巧、绩效结果或行为频率；
3. 是否准确归属于当前维度，而非相邻维度；
4. 是否容易被不同岗位的受测者理解；
5. 是否存在明显“正确答案”暗示或过强社会赞许性；
6. 反向题是否自然，是否避免双重否定；
7. 是否与本批其他题内容或考察点重复；
8. 是否需要结合客户实际用语调整。

## 3. D41 成就动机

**核心含义**：渴望挑战并达成高难度目标。  
**维度定义**：个体被具有挑战性的目标所吸引，并从争取和达成高难度成果中获得意义与满足的内在倾向。  
**边界说明**：侧重对高难度目标、较高标准和艰巨成果的内在偏好；不直接测量完成任务的能力、目标分解与跟踪技巧、承压表现或实际绩效。与超越动机相比，本维度关注挑战性成就本身，不要求持续突破个人极限；与胜任动机相比，不以向他人证明能力为核心。

|---|---|---|---|---|---|
| D41-Q01 | 在可选目标中，具有较高难度的目标更能吸引我。 | 高难目标吸引 | 正向 | 待审核 |  |
| D41-Q02 | 如果一项目标需要付出充分努力才能实现，我会更想争取它。 | 努力门槛吸引 | 正向 | 待审核 |  |
| D41-Q03 | 达成高于常规标准的成果会给我带来强烈满足感。 | 超常成果满足 | 正向 | 待审核 |  |
| D41-Q04 | 想到自己有机会完成一项艰巨任务，我会感到振奋。 | 艰巨任务期待 | 正向 | 待审核 |  |
| D41-Q05 | 我愿意为有挑战性的成果设定较高的目标标准。 | 高标准设定意愿 | 正向 | 待审核 |  |
| D41-Q06 | 即使达成把握不高，具有挑战性的目标仍会吸引我。 | 低把握挑战吸引 | 正向 | 待审核 |  |
| D41-Q07 | 可以自行选择目标时，我更偏好把握较大的容易目标。 | 易达目标偏好 | 反向 | 待审核 |  |

### D41 审核提示

- `D41-Q01` 测量目标吸引力，`D41-Q05` 测量愿意接受的目标标准，审核时需确认两题区分充分；
- `D41-Q06`、`D41-Q08` 关注难度和达成把握对追求愿望的影响，不用于判断风险偏好或抗压能力；
- 预测试需重点检验本维度与 D45 超越动机、D47 胜任动机及 D16 目标管理的区分度。

## 4. D42 权力动机

**核心含义**：渴望拥有影响力和主导权。  
**维度定义**：个体希望参与塑造共同事务的方向、对重要决定产生影响并承担主导角色的内在倾向。  
**边界说明**：侧重对影响方向、参与决策和承担主导角色的愿望；不直接测量领导、沟通、说服或决策能力，也不把支配、控制、压制异议或迫使他人服从等行为等同于高分。建设性影响、明确责任和尊重他人边界均可与较高权力动机并存。

|---|---|---|---|---|---|
| D42-Q01 | 在共同事务中，我更希望处于能够影响最终方向的位置。 | 方向影响愿望 | 正向 | 待审核 |  |
| D42-Q02 | 参与制定重要决定比单纯执行既定决定更能吸引我。 | 决策参与偏好 | 正向 | 待审核 |  |
| D42-Q03 | 由我牵头推动一项重要工作，会增强我的投入感。 | 牵头角色投入 | 正向 | 待审核 |  |
| D42-Q04 | 当自己的观点对集体选择产生实质影响时，我会感到满足。 | 影响结果满足 | 正向 | 待审核 |  |
| D42-Q05 | 在职责允许的范围内，我希望对关键事项拥有明确的决定权。 | 关键事项决断愿望 | 正向 | 待审核 |  |
| D42-Q06 | 代表团队表达立场的角色对我有吸引力。 | 立场代表角色偏好 | 正向 | 待审核 |  |
| D42-Q07 | 相比参与确定方向，我更喜欢按照已经确定的安排完成工作。 | 既定安排偏好 | 反向 | 待审核 |  |
| D42-Q08 | 当他人愿意牵头时，我更希望把方向决定交给对方。 | 方向主导让渡 | 反向 | 待审核 |  |

### D42 审核提示

- 本维度正式名称必须保持为“权力动机”，不得回退为参考表原有误写；
- `D42-Q03`、`D42-Q06` 测量对主导或代表角色的偏好，不评价受测者实际带队或表达立场的能力；
- `D42-Q05` 明确限定在职责范围内，避免把越权、集权或违反规则误当作高权力动机；
- 内容审核和预测试应检查高分是否被错误理解为控制他人，并检验其与 D12 团队领导、D36 果断性和 D39 主动性的区分度。

## 5. D43 关系动机

**核心含义**：渴望与人建立温暖的联结。  
**维度定义**：个体重视与工作伙伴形成亲近、互信、有归属感和相互关心关系的内在倾向。  
**边界说明**：侧重对温暖关系、情感联结和群体归属的需要；不直接测量开启交往、表达沟通、维护关系、解决冲突或扩大人脉的能力，也不以实际社交数量判断高低。与人际交往相比，本维度测量“是否渴望联结”，而不是“是否善于建立和维护关系”。

|---|---|---|---|---|---|
| D43-Q01 | 在工作中与人形成真诚而温暖的联结，对我很重要。 | 温暖联结重视 | 正向 | 待审核 |  |
| D43-Q02 | 一个能让我与成员建立亲近关系的团队更吸引我。 | 亲近团队吸引 | 正向 | 待审核 |  |
| D43-Q03 | 与工作伙伴产生彼此信任的感觉会给我带来满足。 | 互信关系满足 | 正向 | 待审核 |  |
| D43-Q04 | 工作伙伴之间能分享真实感受的关系氛围对我有吸引力。 | 真实感受共享偏好 | 正向 | 待审核 |  |
| D43-Q05 | 加入新的团队时，我期待自己成为其中有归属感的一员。 | 团队归属期待 | 正向 | 待审核 |  |
| D43-Q06 | 我希望工作关系中包含对彼此处境的关心。 | 相互关心偏好 | 正向 | 待审核 |  |
| D43-Q07 | 我更喜欢把同事关系保持在事务往来层面。 | 事务关系偏好 | 反向 | 待审核 |  |
| D43-Q08 | 与工作伙伴保持较多情感距离会让我更自在。 | 情感距离舒适 | 反向 | 待审核 |  |

### D43 审核提示

- 全部题目使用“重要、吸引、满足、期待、希望、喜欢、自在”等偏好表述，不以社交技巧或关系维护结果判断关系动机；
- `D43-Q03`、`D43-Q06` 分别关注互信带来的满足和对相互关心的期待，不用于评价合作行为或利他程度；
- `D43-Q07`、`D43-Q08` 描述事务型关系和情感距离偏好，不应被解释为工作态度或道德品质；
- 预测试需检查其与 D02 人际交往、D25 利他精神和 D35 合作性的区分度，并关注不同组织文化下的作答公平性。

## 6. D44 认知动机

**核心含义**：渴望探索未知、追求真理。  
**维度定义**：个体因未知、疑问和事实本身而产生探索兴趣，并从理解原理、澄清事实和接近真相中获得满足的内在倾向。  
**边界说明**：侧重认识未知和求真的内在驱力；不直接测量知识储备、推理能力、信息处理技巧、创新产出，也不以参加培训、阅读资料、更新知识或掌握技能等持续学习行为代替认知动机。

| 题目编号 | 题目 | 考察点 | 方向 | 审核结论 | 审核意见 |
|---|---|---|---|---|---|
| D44-Q01 | 遇到尚无解释的现象时，我会产生弄清其原理的强烈兴趣。 | 未解现象好奇 | 正向 | 待审核 |  |
| D44-Q02 | 比起直接接受结论，我更享受追问结论为何成立。 | 结论原理追问 | 正向 | 待审核 |  |
| D44-Q03 | 一个陌生领域中尚未被我理解的部分会吸引我去探索。 | 陌生未知吸引 | 正向 | 待审核 |  |
| D44-Q04 | 当证据与原有看法冲突时，我很想找到更符合事实的解释。 | 证据冲突求真 | 正向 | 待审核 |  |
| D44-Q05 | 即使一个复杂问题暂时没有实际用途，它本身也能引起我的兴趣。 | 非功利问题兴趣 | 正向 | 待审核 |  |
| D44-Q06 | 弄清事情实际是怎样的，会给我带来明显的满足感。 | 事实澄清满足 | 正向 | 待审核 |  |
| D44-Q07 | 对于与当前任务无直接关系的问题，我对其背后原理兴趣不大。 | 任务外原理淡漠 | 反向 | 待审核 |  |
| D44-Q08 | 已有可用结论时，我不想再探究它成立的原因。 | 可用结论即止 | 反向 | 待审核 |  |

### D44 审核提示

- `D44-Q01`、`D44-Q03` 关注未知带来的探索兴趣，不要求受测者实际开展学习活动；
- `D44-Q04` 测量接近事实真相的愿望，不评价证据分析或逻辑推理能力；
- `D44-Q05` 用于区分求知本身与即时功利用途，认知访谈需检查不同岗位对“复杂问题”的理解是否一致；
- 预测试需重点检验本维度与 D06 持续学习、D28 求真务实、D40 创新性及 D05 逻辑思维的区分度。

## 8. 审核后处理

1. 汇总每道题的审核结论和修改意见；
2. 对“修改”和“待讨论”题目生成第二版措辞；
3. 检查 D41–D44 以及相邻维度之间的题目重复、考察点重复和串题风险；
4. 重点复核 D42 是否把建设性影响误写为控制他人，D43 是否误测人际交往能力，D44 是否误测持续学习行为；
5. 本批四个维度确认后，再生成下一批维度；
6. 48 个维度全部审定后，汇总为系统导入工作簿；
7. 正式上线前开展预测试，并依据项目分析和信效度检验结果决定是否修改或替换题目。
