# 胜任力测验候选题审阅稿（第 10 批）

**版本**：V0.2  
**日期**：2026-07-24  
**范围**：D37–D40，共 4 个维度、32 道题  
**状态**：AI 测试题初稿（仅供测试与专家审阅，已完成一次内容审查），未经过信效度验证  
**依据**：[胜任力测验需求说明书](competency-assessment-requirements.md)、[48 维度参考表](2600724胜任力测验维度.xlsx)

## 1. 本批生成规则

1. 每个维度直接生成 8 道候选题，共 32 道；题目编号按维度内 Q01–Q08 连续编排；
2. 全部使用中性职场措辞，不限定具体行业、组织、岗位、学历、年龄、性别或正式管理身份；
3. 每道题只描述一个可辨识的行为或反应，不把多个行为合并在同一题中；
4. 每个维度暂按 6 道正向题、2 道反向题配置；
5. 所有题目统一使用五级选项：非常不符合、不太符合、一般、比较符合、非常符合；
6. 正向题依次计 1、2、3、4、5 分，反向题依次计 5、4、3、2、1 分；
7. 考察点仅用于说明题目意图，不单独计分，且本批 32 道题的考察点互不重复；
8. 一道题只归属于一个维度，不以同一道题同时测量抗压性、适应性、主动性或创新性；
9. D37 聚焦压力下的稳定发挥，D38 聚焦变化后的自我调整，D39 聚焦未获具体安排时启动行动，D40 聚焦对新思路的探索与试验；
10. 题目避免模糊频率词、双重否定、绝对化表述和过于明显的正确答案暗示。

> 重要说明：本批题目仅供测试、专家审阅与后续预测试准备，不代表已经完成心理测量学验证。正式用于人才评价前，应经过内容效度审核、认知访谈、预测试、项目分析和信效度检验；不得仅凭本批 AI 初稿直接用于录用、淘汰或晋升决策。

## 2. 统一审核标记

请审核人将每题的“审核结论”填写为以下一种：

- **保留**：题意、归属和方向均可直接使用；
- **修改**：维度归属正确，但措辞需要调整；
- **删除**：与维度不符、与其他题重复或存在明显偏差；
- **待讨论**：存在跨维度边界或业务解释分歧。

建议审核时重点检查：

1. 是否只测量一个明确行为；
2. 是否准确归属于当前维度，而非相邻维度；
3. 是否容易被不同岗位的受测者理解；
4. 是否存在明显“正确答案”暗示或过强社会赞许性；
5. 反向题是否自然，是否避免双重否定；
6. 是否包含模糊频率词或绝对化表述；
7. 是否与本批其他题内容或考察点重复；
8. 是否需要结合客户实际用语调整。

## 3. D37 抗压性

**核心含义**：承受压力时保持稳定发挥。  
**边界说明**：侧重在期限、任务量、结果关注或阶段失利带来压力时调节状态，并保持注意、判断、回应和工作质量的稳定；不测量面对变化时的调整速度、未获安排时是否主动行动，也不测量方案是否新颖。

| 题目编号 | 题目 | 考察点 | 方向 | 审核结论 | 审核意见 |
|---|---|---|---|---|---|
| D37-Q01 | 面对紧迫期限时，我仍按既定质量要求处理手头工作。 | 期限压力下质量保持 | 正向 | 待审核 |  |
| D37-Q02 | 多项任务同时催办时，我能把注意力集中在当前优先事项上。 | 并发催办下注意聚焦 | 正向 | 待审核 |  |
| D37-Q03 | 重要工作受到质疑时，我的回应仍围绕任务事实。 | 受质疑时回应稳定 | 正向 | 待审核 |  |
| D37-Q04 | 工作出现阶段性失利后，我能把注意力重新放到下一步任务上。 | 阶段失利后注意复位 | 正向 | 待审核 |  |
| D37-Q05 | 压力使工作节奏加快时，我会为关键步骤保留必要的处理时间。 | 压力加速时节奏调节 | 正向 | 待审核 |  |
| D37-Q06 | 在结果受到高度关注的任务中，我仍依据现有信息作出判断。 | 高关注任务中判断稳定 | 正向 | 待审核 |  |
| D37-Q07 | 工作压力上升时，我会先追求处理速度，再补做关键核对。 | 压力下关键核对后置 | 反向 | 待审核 |  |
| D37-Q08 | 等待重要结果期间，我的注意力容易被担忧占用。 | 结果等待时担忧干扰 | 反向 | 待审核 |  |

### D37 审核提示

- `D37-Q02` 只在多项催办形成压力时测量注意稳定，不评价日常任务排序或统筹规划能力；
- `D37-Q04` 关注失利后的状态复位，未要求受测者改变目标、流程或工作方法；
- `D37-Q05`、`D37-Q07` 涉及关键步骤，预测试时需检查其与严谨性的区分效度；
- 本维度应通过不同压力来源检验稳定发挥，不应把工作负荷大小本身当作能力高低。

## 4. D38 适应性

**核心含义**：面对变化能快速自我调整。  
**边界说明**：侧重目标、流程、分工、资源或情境改变后，及时调整个人重点、步骤、衔接方式和投入状态；不测量压力承受程度、是否在无人安排时发起行动，也不要求提出前所未有的做法。

| 题目编号 | 题目 | 考察点 | 方向 | 审核结论 | 审核意见 |
|---|---|---|---|---|---|
| D38-Q01 | 工作目标被重新定义后，我会据此调整当前任务的取舍。 | 目标变化后取舍调整 | 正向 | 待审核 |  |
| D38-Q02 | 使用的工作流程更换后，我能按照新流程重新安排自己的步骤。 | 流程切换后步骤重排 | 正向 | 待审核 |  |
| D38-Q03 | 协作分工发生变化时，我会调整与相关人员的信息衔接方式。 | 分工变化后衔接调整 | 正向 | 待审核 |  |
| D38-Q04 | 可用资源与原计划不同时，我会改用与现有条件匹配的推进方式。 | 资源变化后方式匹配 | 正向 | 待审核 |  |
| D38-Q05 | 进入不熟悉的工作情境后，我能较快找到适合自己的工作节奏。 | 陌生情境中节奏建立 | 正向 | 待审核 |  |
| D38-Q06 | 原有做法不再适用时，我能切换到已经明确可用的替代做法。 | 原有方法失效后切换 | 正向 | 待审核 |  |
| D38-Q07 | 任务要求已经更新时，我仍会沿用原先的处理重点。 | 要求更新后重点滞留 | 反向 | 待审核 |  |
| D38-Q08 | 工作安排突然改变后，我需要较长过渡时间才能恢复投入。 | 突发变动后投入恢复 | 反向 | 待审核 |  |

### D38 审核提示

- `D38-Q01`、`D38-Q04` 均以外部条件已经改变为前提，测量随条件调整，而非预先规划或整合资源；
- `D38-Q06` 明确切换到已有可用做法，不以方案新颖性作为判断依据，以此区别于创新性；
- `D38-Q08` 关注变化引起的过渡速度，不以任务量、期限或结果压力作为刺激源；
- 预测试需覆盖流程、分工和资源等不同变化类型，并检查岗位经历差异是否影响作答公平性。

## 5. D39 主动性

**核心含义**：不等安排即主动采取行动。  
**边界说明**：侧重在目标和职责允许的范围内，识别可推进事项，并在未收到具体安排、提醒或完整步骤时启动行动；不测量压力下的稳定、对外部变化的顺应或做法的新颖程度，也不等同于越权决策。

| 题目编号 | 题目 | 考察点 | 方向 | 审核结论 | 审核意见 |
|---|---|---|---|---|---|
| D39-Q01 | 发现职责范围内有一项明确待办尚未被安排时，我会着手推进。 | 未安排待办自主启动 | 正向 | 待审核 |  |
| D39-Q02 | 工作目标已经明确但步骤尚未指定时，我会先启动可确认的第一步。 | 路径未定时首步启动 | 正向 | 待审核 |  |
| D39-Q03 | 后续任务需要提前准备材料时，我会在收到提醒前开始整理。 | 提醒前准备前置材料 | 正向 | 待审核 |  |
| D39-Q04 | 自己的工作因缺少信息而停住时，我会主动联系能够提供信息的人。 | 信息缺口主动追索 | 正向 | 待审核 |  |
| D39-Q05 | 看到工作衔接处存在无人处理的空档时，我会发起对该空档的责任确认。 | 衔接空档发起确认 | 正向 | 待审核 |  |
| D39-Q06 | 完成当前任务后，如果目标还有可推进部分，我会自行选择下一项合适行动。 | 阶段完成后续行动 | 正向 | 待审核 |  |
| D39-Q07 | 职责内的任务方向已经清楚时，我仍会等到收到具体安排后再开始。 | 明确任务等待指令 | 反向 | 待审核 |  |
| D39-Q08 | 发现一个可以立即处理的小缺口时，我会等它进入正式计划后再行动。 | 即时缺口等待排期 | 反向 | 待审核 |  |

### D39 审核提示

- `D39-Q01`、`D39-Q02` 均限定在目标或职责已经明确的情境，测量启动时点，不鼓励越权或在信息不足时盲目行动；
- `D39-Q04`、`D39-Q05` 关注主动发起解除阻塞的动作，不评价沟通质量或跨部门流程协调结果；
- `D39-Q06` 测量当前任务完成后的自发续接，不以目标难度或成就追求作为判断依据；
- 反向题保留等待指令或正式排期的现实取舍，预测试时需检查是否因组织授权文化产生系统性偏差。

## 6. D40 创新性

**核心含义**：不墨守成规、乐于探索新思路。  
**边界说明**：侧重重新审视惯例、形成不同路径、迁移跨领域做法，并通过可控尝试完善新思路；不只是顺应已经发生的变化，也不以是否率先行动或是否解决某个具体问题作为判断标准。

| 题目编号 | 题目 | 考察点 | 方向 | 审核结论 | 审核意见 |
|---|---|---|---|---|---|
| D40-Q01 | 面对沿用已久的做法时，我会重新检查其中的默认前提是否仍成立。 | 惯例前提重新审视 | 正向 | 待审核 |  |
| D40-Q02 | 为同一目标设计做法时，我会提出路径不同的备选思路。 | 异质备选思路生成 | 正向 | 待审核 |  |
| D40-Q03 | 接触到其他领域的做法时，我会思考它能否转化到当前工作。 | 跨领域方法转化 | 正向 | 待审核 |  |
| D40-Q04 | 一个新思路尚未验证时，我会先用小范围尝试检验它。 | 新思路小范围试验 | 正向 | 待审核 |  |
| D40-Q05 | 试用新做法得到反馈后，我会据此调整下一版方案。 | 试验反馈迭代 | 正向 | 待审核 |  |
| D40-Q06 | 现有方式能够完成任务但投入偏高时，我会探索不同路径。 | 高投入方法替代探索 | 正向 | 待审核 |  |
| D40-Q07 | 现有方法能够交付结果时，我会直接沿用，不再比较其他思路。 | 可用方案惯性沿用 | 反向 | 待审核 |  |
| D40-Q08 | 对于缺少先例的想法，我更愿意等待成熟做法出现后再考虑。 | 新颖想法延后考察 | 反向 | 待审核 |  |

### D40 审核提示

- `D40-Q01` 关注对惯例前提的重新审视，不把质疑本身或搜集事实等同于创新成果；
- `D40-Q03` 测量跨情境转化做法，不评价学习投入或信息整理能力；
- `D40-Q04`、`D40-Q05` 强调小范围检验和依据反馈迭代，避免把创新性理解为不顾风险地追求新奇；
- `D40-Q06` 在现有方式仍可用时探索替代路径，以此区别于因外部变化被迫调整的适应性和因任务无人安排而先行动的主动性。

## 8. 审核后处理

1. 汇总每道题的审核结论和修改意见；
2. 对“修改”和“待讨论”题目生成第二版措辞；
3. 复核本批 32 个考察点是否保持唯一，并检查题干之间的语义重复；
4. 重点检查 D37–D40 相互之间以及与相邻维度的串题风险；
5. 本批四个维度确认后，再进入后续维度的候选题审阅；
6. 48 个维度全部审定后，汇总为系统导入工作簿；
7. 正式使用前开展认知访谈和预测试，并依据项目分析、信度与效度结果决定保留、修改或替换题目。
