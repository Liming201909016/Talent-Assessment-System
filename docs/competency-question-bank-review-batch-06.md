# 胜任力测验候选题审阅稿（第 6 批）

**版本**：V0.2  
**日期**：2026-07-24  
**范围**：D21–D24，共 4 个维度、32 道题  
**状态**：仅测试用候选题初稿（已完成一次内容审查），未经过信效度验证  
**依据**：[胜任力测验需求说明书](competency-assessment-requirements.md)、[48 维度参考表](2600724胜任力测验维度.xlsx)

## 1. 本批生成规则

1. 每个维度直接生成 8 道候选题；
2. 全部使用中性职场措辞，不限定具体行业或正式管理身份；
3. 每个维度按前 6 道正向题、后 2 道反向题配置；
4. 所有题目统一使用五级选项：非常不符合、不太符合、一般、比较符合、非常符合；
5. 正向题依次计 1、2、3、4、5 分，反向题依次计 5、4、3、2、1 分；
6. 考察点仅用于说明题目意图，不单独计分，且本批 32 道题的考察点互不重复；
7. 一道题只归属于一个维度；
8. 每道题聚焦一个行为或判断，避免模糊频率副词、双重否定、绝对化措辞和价值口号；
9. D22 的客户包括外部客户和内部服务对象；D23 既测量对制度底线的遵守，也认可通过正式渠道处理规则不适用情形，不把盲从规则作为高分表现；
10. 题目避免包含具体组织、岗位、学历、年龄、性别等限制性信息。

> 重要说明：本批题目仅供测试和专家审阅，不代表已经完成心理测量学验证。正式用于人才评价前，应经过内容效度审核、认知访谈、预测试、项目分析和信效度检验；不宜仅凭本候选题初稿直接用于录用、淘汰或其他重要人才决策。

## 2. 统一审核标记

请审核人将每题的“审核结论”填写为以下一种：

- **保留**：题意、归属和方向均可直接使用；
- **修改**：维度归属正确，但措辞需要调整；
- **删除**：与维度不符、与其他题重复或存在明显偏差；
- **待讨论**：存在跨维度边界或业务解释分歧。

建议审核时重点检查：

1. 是否只测量一个明确行为或判断；
2. 是否准确归属于当前维度，而非相邻维度；
3. 是否容易被不同岗位的受测者理解；
4. 是否因价值暗示而存在较强社会赞许性；
5. 反向题是否自然，是否避免双重否定；
6. 是否使用模糊频率副词或绝对化措辞；
7. 题目之间是否重复，考察点是否保持批内唯一；
8. 是否需要结合客户实际用语调整。

## 3. D21 敬业奉献

**核心含义**：视工作为责任，全心投入。  
**边界说明**：侧重基于职责承诺持续投入并对交付负责；不把无边界加班、牺牲健康或服从所有额外要求视为高分，也不直接测量成就动机、抗压稳定性或具体执行技能。

| 题目编号 | 题目 | 考察点 | 方向 | 审核结论 | 审核意见 |
|---|---|---|---|---|---|
| D21-Q01 | 接受一项工作时，我会明确自己对交付结果承担的责任。 | 责任归属确认 | 正向 | 待审核 |  |
| D21-Q02 | 工作推进遇到阻力时，我会保持对所负责事项的投入。 | 受阻事项投入 | 正向 | 待审核 |  |
| D21-Q03 | 工作内容较为琐碎时，我仍会按约定标准完成自己负责的部分。 | 琐碎职责完成 | 正向 | 待审核 |  |
| D21-Q04 | 任务进入收尾阶段时，我会把精力放在尚未完成的职责上。 | 收尾责任聚焦 | 正向 | 待审核 |  |
| D21-Q05 | 发现自己的交付存在疏漏时，我会投入时间完成修正。 | 交付疏漏修正 | 正向 | 待审核 |  |
| D21-Q06 | 需要他人接续工作时，我会将自己负责的部分整理到可接手状态。 | 接续状态准备 | 正向 | 待审核 |  |
| D21-Q07 | 工作内容与个人兴趣不一致时，我会降低对它的投入程度。 | 兴趣影响投入 | 反向 | 待审核 |  |
| D21-Q08 | 一项工作与个人评价关联较小时，我会降低对交付标准的关注。 | 评价影响标准 | 反向 | 待审核 |  |

### D21 审核提示

- `D21-Q02` 涉及阻力情境，但测量重点是责任承诺带来的投入，不是压力下的情绪稳定；
- `D21-Q03`、`D21-Q04`、`D21-Q05` 均以约定职责和合理工作边界为前提，不用于鼓励无边界加班；
- 本维度具有较强社会赞许性，认知访谈应检查受测者是否按真实行为作答，而非选择价值上更受认可的答案。

## 4. D22 客户至上

**核心含义**：一切工作以客户价值为出发点；客户包括外部客户和内部服务对象。  
**边界说明**：侧重理解服务对象的实际需要，并以可持续的客户价值判断方案、顺序和交付方式；不等同于满足每项请求、绕过制度边界、作出不可兑现的承诺或只追求短期满意。

| 题目编号 | 题目 | 考察点 | 方向 | 审核结论 | 审核意见 |
|---|---|---|---|---|---|
| D22-Q01 | 收到服务对象提出的需求时，我会先确认对方希望解决的实际问题。 | 实际需求澄清 | 正向 | 待审核 |  |
| D22-Q02 | 比较不同工作方案时，我会判断哪种方案能为服务对象带来更实际的价值。 | 客户价值比较 | 正向 | 待审核 |  |
| D22-Q03 | 服务对象反馈使用不便时，我会据此调整可改进的交付环节。 | 使用反馈改进 | 正向 | 待审核 |  |
| D22-Q04 | 设计服务流程时，我会把服务对象获取结果的便利性纳入考虑。 | 服务便利设计 | 正向 | 待审核 |  |
| D22-Q05 | 资源有限需要排序时，我会根据事项对服务对象的价值安排优先次序。 | 客户价值排序 | 正向 | 待审核 |  |
| D22-Q06 | 无法按原请求提供服务时，我会给出可行的替代选择。 | 替代选择提供 | 正向 | 待审核 |  |
| D22-Q07 | 交付内容达到内部要求后，我会停止了解服务对象的实际使用效果。 | 内部达标止步 | 反向 | 待审核 |  |
| D22-Q08 | 服务对象提出与原有设想不同的需要时，我会优先维持既定做法。 | 既定做法固守 | 反向 | 待审核 |  |

### D22 审核提示

- 审核时需确认不同岗位都能把“服务对象”理解为与自身工作相关的外部客户或内部协作对象；
- `D22-Q03`、`D22-Q05`、`D22-Q06` 均以合规、职责范围和可持续交付为边界，不把无条件接受请求视为客户至上；
- `D22-Q08` 需通过认知访谈区分合理的范围控制与忽视客户实际价值，避免因岗位权限差异产生偏差。

## 5. D23 规则意识

**核心含义**：视制度与流程为不可突破的底线。  
**边界说明**：侧重识别并遵守强制性制度、必要流程和授权边界，也包括在规则不适用于当前情形时通过正式渠道反馈或申请调整；不把机械照搬、回避判断或对规则问题保持沉默视为高分，也不直接测量一般严谨性。

| 题目编号 | 题目 | 考察点 | 方向 | 审核结论 | 审核意见 |
|---|---|---|---|---|---|
| D23-Q01 | 开展一项工作前，我会确认与该事项相关的制度要求。 | 适用制度确认 | 正向 | 待审核 |  |
| D23-Q02 | 选择处理方式时，我会识别其中属于强制要求的边界。 | 强制边界识别 | 正向 | 待审核 |  |
| D23-Q03 | 发现既定流程不适合当前情形时，我会通过规定渠道提出调整申请。 | 调整渠道使用 | 正向 | 待审核 |  |
| D23-Q04 | 业务时限与必要审批发生冲突时，我会保留审批环节。 | 必要审批保留 | 正向 | 待审核 |  |
| D23-Q05 | 对规则要求存在不同理解时，我会在行动前向有权解释者核实。 | 规则解释核实 | 正向 | 待审核 |  |
| D23-Q06 | 执行关键流程时，我会保留规定要求的过程记录。 | 关键过程留痕 | 正向 | 待审核 |  |
| D23-Q07 | 任务时间紧张时，我会把规定步骤延后处理。 | 规定步骤延后 | 反向 | 待审核 |  |
| D23-Q08 | 我认为结果可控时，我会用个人判断替代流程要求的复核。 | 个人判断替代复核 | 反向 | 待审核 |  |

### D23 审核提示

- `D23-Q01` 关注主动确认适用要求，`D23-Q02` 关注识别强制边界，两题不用于考查制度条文记忆；
- `D23-Q03` 将正式反馈和申请调整纳入正向表现，用于避免把盲从规则误判为高规则意识；
- `D23-Q04`、`D23-Q07`、`D23-Q08` 需结合客户制度识别真正必要的步骤，并与获授权的应急或例外流程区分。

## 6. D24 全局观念

**核心含义**：超越本位，以组织整体利益为重。  
**边界说明**：侧重在目标、资源、责任和成效取舍中考虑组织整体，而非只优化本方结果；不直接测量长期战略判断、跨部门协调技巧或无条件牺牲局部合理利益。

| 题目编号 | 题目 | 考察点 | 方向 | 审核结论 | 审核意见 |
|---|---|---|---|---|---|
| D24-Q01 | 评估本方方案时，我会把它对其他工作环节的影响纳入判断。 | 跨环节影响评估 | 正向 | 待审核 |  |
| D24-Q02 | 局部目标与组织整体目标发生冲突时，我会按整体目标调整本方安排。 | 整体目标优先 | 正向 | 待审核 |  |
| D24-Q03 | 安排共享资源时，我会依据组织层面的优先次序作出取舍。 | 共享资源取舍 | 正向 | 待审核 |  |
| D24-Q04 | 本方收益会增加其他环节负担时，我会重新评估这项做法。 | 局部收益校准 | 正向 | 待审核 |  |
| D24-Q05 | 跨团队事项出现责任空档时，我会推动形成有利于整体结果的承接安排。 | 整体责任补位 | 正向 | 待审核 |  |
| D24-Q06 | 评估一项改进的成效时，我会以组织整体结果作为判断依据。 | 整体成效判断 | 正向 | 待审核 |  |
| D24-Q07 | 选择投入方向时，我会把本方能否直接受益作为主要依据。 | 本方受益导向 | 反向 | 待审核 |  |
| D24-Q08 | 本方指标改善时，我会把其他环节增加的成本放在次要位置。 | 他环节成本降权 | 反向 | 待审核 |  |

### D24 审核提示

- `D24-Q01`、`D24-Q04` 关注局部选择对组织链条的影响，不要求受测者参与长期战略制定；
- `D24-Q03`、`D24-Q05` 分别与资源整合、组织协调相邻，但本题测量重点是整体利益取舍，而非资源获取或协调技巧；
- `D24-Q08` 需在预测试中检查受测者是否能区分合理的成本分工与仅为本方指标转移成本。

## 8. 审核后处理

1. 汇总每道题的审核结论和修改意见；
2. 对“修改”和“待讨论”题目生成第二版措辞；
3. 检查 D21–D24 以及相邻维度之间的题目重复和串题风险；
4. 本批四个维度确认后，再生成下一批维度；
5. 48 个维度全部审定后，汇总为系统导入工作簿；
6. 正式上线前开展预测试，并依据项目分析和信效度检验结果决定是否替换题目。
