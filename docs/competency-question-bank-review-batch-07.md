# 胜任力测验候选题审阅稿（第 7 批）

**版本**：V0.2  
**日期**：2026-07-24  
**范围**：D25–D28，共 4 个维度、32 道题  
**用途**：仅用于题库流程、界面、计分和人工审核测试  
**状态**：AI 测试题初稿（已完成一次内容审查），未经过信效度验证  
**依据**：[胜任力测验需求说明书](competency-assessment-requirements.md)、[48 维度参考表](2600724胜任力测验维度.xlsx)

## 1. 本批生成规则

1. 每个维度直接生成 8 道候选题；
2. 全部使用中性职场措辞，不限定具体行业，每题只描述一个可观察行为；
3. 每个维度暂按 6 道正向题、2 道反向题配置；
4. 所有题目统一使用五级符合度选项：非常不符合、不太符合、一般、比较符合、非常符合；
5. 正向题依次计 1、2、3、4、5 分，反向题依次计 5、4、3、2、1 分；
6. 考察点仅用于说明题目意图，不单独计分，且 32 道题的考察点在本批内不重复；
7. 一道题只归属于一个维度；
8. 题目避免包含具体组织、岗位、学历、年龄、性别等限制性信息；
9. 题干避免使用“总是、从不、经常、通常、往往、容易、倾向于”等频率或特质化措辞，避免双重否定、绝对化表达和明显的道德答案暗示；
10. D25 的高分行为限定在合理职责、时间和能力边界内，不把无边界牺牲、替他人长期兜底或损害自身既定任务美化为利他。

> 重要说明：本批题目仅用于题库流程、界面、计分和人工审核测试，不代表已经完成心理测量学验证。正式用于人才评价前，应经过内容效度审核、认知访谈、预测试、项目分析和信效度检验；不得仅凭本批 AI 测试题用于录用、淘汰或其他实际人才决策。

## 2. 统一审核标记

请审核人将每题的“审核结论”填写为以下一种：

- **保留**：题意、归属和方向均可直接使用；
- **修改**：维度归属正确，但措辞需要调整；
- **删除**：与维度不符、与其他题重复或存在明显偏差；
- **待讨论**：存在跨维度边界或业务解释分歧。

建议审核时重点检查：

1. 是否只测量一个明确且可观察的行为；
2. 是否准确归属于当前维度，而非相邻维度；
3. 是否容易被不同岗位的受测者理解；
4. 是否存在明显“正确答案”暗示或过强社会赞许性；
5. 反向题是否自然，是否避免双重否定；
6. 是否与本批其他题内容或考察点重复；
7. 是否需要结合客户实际用语调整。

## 3. D25 利他精神

**核心含义**：乐于助人，不计较个人得失。  
**边界说明**：侧重在合理职责、时间和能力范围内回应他人需要、提供实际支持，并不过度以个人回报决定是否帮助；不把牺牲既定职责、无条件承诺、替他人长期兜底或违反规则视为高分，也不直接测量一般合作意愿、敬业投入或人际亲近程度。

| 题目编号 | 题目 | 考察点 | 方向 | 审核结论 | 审核意见 |
|---|---|---|---|---|---|
| D25-Q01 | 收到同事提出的工作求助时，我会明确回复自己可以提供的支持。 | 求助响应 | 正向 | 待审核 |  |
| D25-Q02 | 发现同事缺少完成任务所需的信息时，我会把自己掌握的相关信息提供给对方。 | 信息补给 | 正向 | 待审核 |  |
| D25-Q03 | 在不影响既定任务的情况下，我会安排一段时间协助同事处理工作难点。 | 有界投入 | 正向 | 待审核 |  |
| D25-Q04 | 团队成员临时无法处理一项任务时，我会承担其中力所能及的支援部分。 | 临时补位 | 正向 | 待审核 |  |
| D25-Q05 | 协助内容不涉及个人署名时，我也会提供力所能及的支持。 | 署名无关 | 正向 | 待审核 |  |
| D25-Q06 | 接受工作求助时，我会向对方说明自己能够承担的支持范围。 | 边界说明 | 正向 | 待审核 |  |
| D25-Q07 | 同事提出合理求助时，我会根据对方过去是否帮过我来安排回应顺序。 | 互惠排序 | 反向 | 待审核 |  |
| D25-Q08 | 面对临时支援请求，即使已有任务留出余量，我也会优先保留这部分时间。 | 余量自留 | 反向 | 待审核 |  |

### D25 审核提示

- `D25-Q03`、`D25-Q06` 共同限定帮助的投入和承诺边界，审核时不得把牺牲既定任务或无限承担解释为更高利他水平；
- `D25-Q05`、`D25-Q07` 涉及个人认可与互惠考虑，需在认知访谈中检查社会赞许性以及受测者对合理利益安排的理解；
- `D25-Q08` 需检查能否区分合理保留任务缓冲与单纯回避支援，若岗位工作对突发风险高度敏感，应结合场景修改措辞。

## 4. D26 公平公正

**核心含义**：处理事务客观公道、不偏不倚。  
**边界说明**：侧重依据公开条件、一致标准和事项事实作出处理，并为相关方提供合理程序与差异说明；公平不等于忽略实质差异而机械地采用相同结果，也不直接测量制度服从、工作严谨或人际和谐。

| 题目编号 | 题目 | 考察点 | 方向 | 审核结论 | 审核意见 |
|---|---|---|---|---|---|
| D26-Q01 | 分配工作机会时，我会依据事先说明的条件作出选择。 | 条件公开 | 正向 | 待审核 |  |
| D26-Q02 | 评价同类工作结果时，我会采用同一套事先说明的标准。 | 标准一致 | 正向 | 待审核 |  |
| D26-Q03 | 处理争议时，我会在相关各方都有陈述机会后作出判断。 | 陈述机会 | 正向 | 待审核 |  |
| D26-Q04 | 与熟悉的同事发生意见分歧时，我会依据事项本身的信息作出判断。 | 关系中立 | 正向 | 待审核 |  |
| D26-Q05 | 个人关系可能影响判断时，我会安排无直接利害关系的人复核。 | 独立复核 | 正向 | 待审核 |  |
| D26-Q06 | 对不同情况采用不同处理方式时，我会说明差异依据。 | 差异说明 | 正向 | 待审核 |  |
| D26-Q07 | 资源有限时，我会把配合熟悉度作为优先分配的依据。 | 熟悉偏好 | 反向 | 待审核 |  |
| D26-Q08 | 处理意见分歧时，我会把职位高低作为判断意见分量的依据。 | 职位偏重 | 反向 | 待审核 |  |

### D26 审核提示

- `D26-Q01`、`D26-Q02` 分别测量分配条件与评价标准，不要求所有对象获得相同结果；
- `D26-Q05` 测量对潜在偏差的程序性控制，需检查不同岗位是否具备安排他人复核的现实机会；
- `D26-Q07`、`D26-Q08` 采用真实工作中的便利性和层级线索作为反向情境，预测试需检查其社会赞许性与区分度。

## 5. D27 共生共赢

**核心含义**：追求各方共同受益、共同成长。  
**边界说明**：侧重在合作中识别并兼顾各方核心收益，使投入、成果和后续发展具有可持续性；不等于无原则让利或平均分配，也不直接测量任务配合、人际关系维护、客户服从或一般资源协调。

| 题目编号 | 题目 | 考察点 | 方向 | 审核结论 | 审核意见 |
|---|---|---|---|---|---|
| D27-Q01 | 讨论合作方案时，我会明确各参与方希望获得的实际收益。 | 收益识别 | 正向 | 待审核 |  |
| D27-Q02 | 设计合作分工时，我会检查各方承担的投入与获得的收益是否相称。 | 投益平衡 | 正向 | 待审核 |  |
| D27-Q03 | 合作各方出现利益分歧时，我会提出兼顾各方核心诉求的方案。 | 诉求兼顾 | 正向 | 待审核 |  |
| D27-Q04 | 协作形成可复用的方法后，我会把方法分享给参与方。 | 方法共享 | 正向 | 待审核 |  |
| D27-Q05 | 选择合作方式时，我会评估它能否为后续合作保留空间。 | 合作延续 | 正向 | 待审核 |  |
| D27-Q06 | 合作告一段落时，我会与参与方复盘各自获得的价值。 | 价值复盘 | 正向 | 待审核 |  |
| D27-Q07 | 合作方案已满足本方目标时，我会减少对其他参与方收益的考虑。 | 单方满足 | 反向 | 待审核 |  |
| D27-Q08 | 分配合作成果时，我会把本方短期收益放在延续合作之前。 | 短期占优 | 反向 | 待审核 |  |

### D27 审核提示

- `D27-Q02` 关注投入与收益的相称关系，不把共赢误写成各方获得完全相同的结果；
- `D27-Q04`、`D27-Q06` 分别测量方法共享与共同价值复盘，需检查是否具有足够不同的行为指向；
- `D27-Q07`、`D27-Q08` 分别涉及其他参与方收益和合作持续性，审核时应避免把组织正当利益维护误判为单方获利。

## 6. D28 求真务实

**核心含义**：尊重事实、注重实效、不搞形式。  
**边界说明**：侧重区分事实与判断、核验信息、用实际结果检查和调整工作，并减少缺乏实际价值的形式环节；不等于忽略必要流程、只追求短期结果，也不直接测量一般逻辑推理、工作严谨、问题解决或绩效考核能力。

| 题目编号 | 题目 | 考察点 | 方向 | 审核结论 | 审核意见 |
|---|---|---|---|---|---|
| D28-Q01 | 汇报工作进展时，我会把已确认的事实与个人判断分开说明。 | 事实判断区分 | 正向 | 待审核 |  |
| D28-Q02 | 引用一项尚未核实的信息前，我会查找可验证的来源。 | 信息溯源 | 正向 | 待审核 |  |
| D28-Q03 | 制定行动方案时，我会把预期产出表述为可检查的结果。 | 结果可检验 | 正向 | 待审核 |  |
| D28-Q04 | 实际效果与预期不一致时，我会根据现场结果调整做法。 | 效果校准 | 正向 | 待审核 |  |
| D28-Q05 | 发现重复环节未产生实际价值时，我会提出简化建议。 | 无效环节精简 | 正向 | 待审核 |  |
| D28-Q06 | 工作完成后，我会用实际结果核对任务目的是否达到。 | 目标核验 | 正向 | 待审核 |  |
| D28-Q07 | 呈现工作成果时，我会把材料形式的完整程度作为主要完成标准。 | 形式替代成果 | 反向 | 待审核 |  |
| D28-Q08 | 既有做法在现场效果不佳时，我会继续按原流程执行到结束。 | 流程机械延续 | 反向 | 待审核 |  |

### D28 审核提示

- `D28-Q01`、`D28-Q02` 分别关注事实表达和信息核验，不把求真务实扩大为一般分析能力；
- `D28-Q03`、`D28-Q06` 分别测量事前结果定义和事后目标核验，审核时需确认二者不构成重复；
- `D28-Q05`、`D28-Q08` 不否定必要流程，预测试需检查受测者能否依据“实际价值”和“现场效果”理解题意。

## 8. 审核后处理

1. 汇总每道题的审核结论和修改意见；
2. 对“修改”和“待讨论”题目生成第二版措辞；
3. 检查 D25–D28、本批内部以及相邻维度之间的题目重复和串题风险；
4. 本批四个维度确认后，再生成下一批维度；
5. 48 个维度全部审定后，汇总为系统导入工作簿；
6. 正式使用前开展认知访谈和预测试，并依据内容效度、项目分析及信效度检验结果决定是否修改或替换题目。
